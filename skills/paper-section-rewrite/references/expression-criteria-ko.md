# 한국어 학술 글 표현 기준 (Level 4 문장 윤문 보강)

`banned-phrases-ko.md`의 금지어와 `writing-principles-ko.md`의 자연스러움 원칙을 보강하는 문장 단위 표현 기준이다. Step 4.i.2 자연스러움 게이트가 이 파일을 불러 쓴다.

출처: [DaleSeo/korean-skills](https://github.com/DaleSeo/korean-skills) (MIT, 커밋 ae12ba2)의 `humanizer`와 `grammar-checker`에서 학술 글에 맞는 항목만 골라 논문 문장 기준으로 다시 썼다. 원 저작권 고지와 라이선스는 `LICENSE-korean-skills`에 둔다. 원 저장소의 쉼표 비율·품사 N-gram·띄어쓰기 경직성 같은 AI 탐지용 통계, 변경률 가드, "불규칙성을 남겨라" 지침은 논문 윤문의 목적과 맞지 않아 가져오지 않았다.

## 0. 세는 법

- **S2 항목**: 표의 "발동" 조건을 한 단락에서 채우면 **1점**이다. 조건 안에서 몇 번 나와도 1점이다.
- **S1 항목**: 한 번만 나와도 **건당 2점**이다. 추상 주어 + 만능 동사(X7)와 결말 관용구(X8)가 해당한다.
- 단락 합계가 **3점 이상이면 ✗**다. 기존 `banned-phrases-ko.md` 항목과 합산한다. 한 문장에 두 패턴이 겹치면 더 분명한 쪽 하나만 센다.
- 아래 "허용" 칸에 해당하면 세지 않는다. 학술 글에서 정착된 용어, 인용된 원문, 수식·정의 문장이 그렇다.

## A. 번역투·잉여 표현

| # | 패턴 | 발동 | 고치는 법 | 허용 |
|---|---|---|---|---|
| X1 | `~에 대해(서)` + 동사. 목적어로 바로 받을 자리 | 단락 2회+ | `X에 대해 분석한다` → `X를 분석한다` | 명사구 수식 `~에 대한 N`은 이 항목 대상이 아님(기존 `에 대한` 규칙은 유지). 의견·태도의 대상은 허용 |
| X2 | `~를 통해` 수단 표현 반복 | 단락 2회+ | `~로`, `~해서`, `~함으로써`로 나눈다. `실험을 통해 확인했다` → `실험으로 확인했다` | 매개 자체가 핵심인 1회 |
| X3 | `~와 관련하여 / ~와 관련된 N` | 단락 2회+ | `보안과 관련하여 강화한다` → `보안을 강화한다`, `관련된 정책` → `정책` | 관계 자체가 정보일 때 |
| X4 | `~에 기반하여 / ~를 바탕으로` | 단락 2회+ | `~로`, `~를 보고`, `~를 근거로`로 나눈다 | `데이터 기반`, `근거 기반`처럼 굳은 합성 용어 |
| X5 | `~를 가지고 있다` | 단락 2회+ | `강한 일반화 능력을 가지고 있다` → `일반화 능력이 강하다` | 구체 물건의 소유 |
| X6 | `~라는 점에서` 인과 결합 | 단락 2회+ | `빠르다는 점에서 효율적이다` → `빨라서 효율적이다` | 한 측면으로 한정하는 평가(`비용 측면에서는 불리하나`) |

## B. 동사·결말 (S1)

| # | 패턴 | 점수 | 고치는 법 | 허용 |
|---|---|---|---|---|
| X7 | **추상 주어 + 만능 동사**: `이 방법은 성능 향상을 가져온다 / 변화를 일으킨다 / 가능성을 제공한다 / 길을 연다` | 건당 2 | 행위자를 살리거나 결과를 서술어로 올린다. `이 방법은 성능 향상을 가져온다` → `이 방법으로 정확도가 3.1%p 오른다` | `이 이론은 X를 설명한다`처럼 학술 정형 서술 |
| X8 | **결말 관용구**: `결론적으로 / 요약하면 / 시사하는 바가 크다 / 주목할 만하다 / 본질적으로 / 이제는 ~할 시점이다 / ~라는 뜻이다 / ~인 셈이다` | 건당 2 | 지우거나 구체 함의 한 문장으로 바꾼다. `시사하는 바가 크다` → 무엇을 시사하는지 쓴다 | 섹션 제목 `결론`. 인용 원문 |

## C. 어휘

| # | 패턴 | 발동 | 고치는 법 | 허용 |
|---|---|---|---|---|
| X9 | **hype 어휘 군집**: `혁신적 / 획기적 / 압도적 / 강력한 / 놀라운 / 전례 없는 / 파격적 / 엄청난` | 단락 2개+ 또는 수치 없이 1개 | 수치나 비교 대상으로 바꾼다. `압도적인 성능` → `기준선보다 12% 높은 성능` | 수치가 바로 붙은 비교 |
| X10 | **`~적 N` 추상 체인**: `전략적 함의 / 구조적 한계 / 본질적 변화 / 근본적 차이` | 단락 3개+ | 풀어쓴다. `구조적 한계` → `구조의 한계` | `통계적 유의성`, `확률적 경사 하강`처럼 굳은 학술 용어 |
| X11 | **지시어 과다**: 앞 문장을 다시 가리키는 `이러한 / 해당 / 상기 / 동` 반복, 대명사 `이것은 / 그것은` | 단락 3회+ | 지시어를 지우고 핵심어를 다시 쓰거나(핵심 용어 고정 원칙), 주어를 뺀다 | 수식·그림·표를 가리키는 `이 식`, `이 그림` |
| X12 | **주어 반복**: 연속 문장이 같은 주어(`본 연구는 / 우리는`)로 시작 | 단락 3문장+ 연속 | 첫 문장에만 쓰고 이후 생략하거나, 주어를 바꿔 시작한다 | 기여 목록처럼 병렬이 의도된 곳 |
| X13 | **불필요한 `-들`**: `많은 실험들 / 여러 기능들 / 세 모델들` | 단락 3회+ | `-들`을 뺀다 | 대비를 위해 복수를 강조한 곳 |

## D. 맞춤법·띄어쓰기 점검 (Step 5.7 저장본 재독에서 한 번 돈다)

문장 윤문 루프에서는 돌리지 않는다. 최종 저장본을 다시 읽을 때 아래만 본다. 확실한 오류만 고치고, 권장 수준은 메모만 한다.

| 항목 | 틀린 예 → 맞는 예 |
|---|---|
| 되 / 돼 | `되요` → `돼요`, `됬다` → `됐다` (`되어`로 풀어 읽어 어색하지 않으면 `돼`) |
| 안 / 않 | `하지 안는다` → `하지 않는다`, `않 되는` → `안 되는` |
| `-ㄹ게` | `할께` → `할게` (`-ㄹ까`는 된소리 그대로 `할까`) |
| 의존명사 띄어쓰기 | `할수있다` → `할 수 있다`, `하는것` → `하는 것`, `~뿐`, `~만큼`, `~데`, `~지` |
| `-로서 / -로써` | 자격은 `로서`, 수단은 `로써` |
| `-던 / -든` | 과거 회상은 `던`, 선택은 `든` |
| 가운뎃점 `·` | 독립 항목의 단순 나열(`쿠키·세션·JWT`)은 쉼표로. 짝·공통 성분(`한·미`, `금·은·동`)에만 쓴다 |
| 숫자 + 단위 | 이 글이 이미 쓰는 쪽(`3개` 또는 `3 개`)으로 통일한다. 새로 고르지 않는다 |

## E. 적용 순서와 주의

1. X1~X13은 기존 Step 4.i.2 표 아래에서 같은 단락 단위로 센다. 합계가 3점 이상이면 점수가 높은 항목부터 고친다.
2. 고칠 때 의미, 수치, 인용, 부정 방향을 바꾸지 않는다. 고친 뒤 4.i.3 논리 게이트가 이어서 확인한다.
3. 같은 문장에서 X7이 걸리고 "단문 원칙"에도 걸리면 먼저 쪼개고, 쪼갠 뒤 X7이 남는지 다시 본다.
4. 이 기준은 "AI 티 제거"가 목적이 아니다. 독자가 한 번에 읽히는 문장이 목적이다. 위 패턴이 없어도 읽기 어려우면 기존 게이트로 잡는다.

## F. 적용 예

수정 전:

> 본 연구는 어텐션 헤드의 역할에 대해 분석한다. 이러한 분석은 모델 해석에 있어 중요한 시사점을 가져온다. 우리는 강력한 탐침 기법을 통해 헤드별 기능을 추출하였고, 이러한 결과는 해당 모델이 문법 정보를 가지고 있음을 보여준다. 결론적으로 본 연구는 시사하는 바가 크다.

점수: X1 `역할에 대해 분석` 1회(발동 미달, 0점), X7 `시사점을 가져온다` 2점, X9 `강력한` 수치 없이 1개 1점, X2 `통해` 1회(0점), X5 `가지고 있음` 1회(0점), X11 `이러한`·`해당` 3회 1점, X8 `결론적으로`·`시사하는 바가 크다` 2점. 합계 6점이므로 ✗.

수정 후:

> 본 연구는 어텐션 헤드가 각각 어떤 역할을 하는지 분석한다. 탐침 분류기로 헤드별 기능을 추출한 결과, <N>개 헤드 중 <M>개가 문법 범주를 구분했다. 이 결과는 모델 내부 표현에 문법 정보가 담겨 있음을 보여준다.

고친 것: 추상 주어 문장을 결과 문장으로 바꾸고, 결말 관용구 문장은 지웠다. 원문에 없던 주장은 새로 넣지 않았다. `<N>`, `<M>` 자리는 원문이나 결과표에서 가져온 값으로 채운다. 원문에 없는 수치를 만들어 넣지 않고, 값이 없으면 수치 없이 사실만 쓴다.
