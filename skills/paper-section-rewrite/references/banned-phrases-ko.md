# 한국어 학술 글 금지·주의 표현

Notion 3주차 문장 6원칙 + paper-digest·humanize 누적 패턴. critic loop의 정량 점검에 사용.

각 항목에 **regex** 칸을 두어 자동 grep 가능하게 함.

---

## 1. 명사형 누적 (Nominalization)

명사 + `-적/-의` 연쇄가 한 문장에 3개 이상이면 가독성 급락.

| 패턴 | 권장 대체 | regex |
|---|---|---|
| `~적인 X` | `~한 X` 또는 풀어쓰기 | `[가-힣]+적인` |
| `~적으로` | `~하여` / `~게` | `[가-힣]+적으로` |
| `~의 ~의 ~의` (관형격 3중) | 풀어 안긴문장으로 | `의\s[^의]+의\s[^의]+의` |

**예:**
- ❌ "본 연구의 핵심적인 기여는 모델적인 일반화 능력의 향상이다."
- ✅ "본 연구는 모델의 일반화 능력을 어떻게 향상시키는지 보인다."

## 2. 의존명사 남용

`것/수/데/때/뿐/만큼` 등 의존명사가 많으면 문장이 흐물흐물해진다.

| 패턴 | 문제 | regex |
|---|---|---|
| `~것이다` (단정) | 단정 약화. 동사로 끝내라 | `것이다\.` |
| `~것으로 본다` / `~것으로 보인다` | 약한 단정. 회피 | `것으로\s+(본다|보인다)` |
| `~수 있다` (능력 X, 가능성) | 명시적 가능성이 아니면 빼라 | `수\s+있다` |
| `~데` (`-는데`, `-(으)ㄴ데`) | 무의식적 연결 어미. 가급적 X | `는데\s|ㄴ데\s|은데\s` |

**임계치 예:** Stage 4 채점에서 `것이다` ≥ 3개/단락이면 "표현" 점수 -1, ≥ 5개면 -2.

**예:**
- ❌ "이러한 결과로부터 모델이 학습한 것이라 할 수 있다."
- ✅ "이 결과는 모델이 학습했음을 보여준다."

---

## 3. 피동 표현 남용

`~됩니다`, `~되어진다`, `~지게 된다` 같은 피동이 잦으면 행위 주체가 흐려진다.

| 패턴 | 문제 | regex |
|---|---|---|
| `~됩니다` | 학술에선 평서 종결 권장. 그리고 능동으로 | `됩니다\.` |
| `~되어진다` | 이중 피동. 항상 X | `되어진다` |
| `~지게 된다` | 우회. 능동 권장 | `지게\s+된다` |
| `~에 의해 ~된다` | 영어 by 직역. 능동으로 | `에\s+의해.*된다` |

**예:**
- ❌ "본 모델은 다양한 환경에서 평가되어진다."
- ✅ "본 연구는 다양한 환경에서 본 모델을 평가한다."

## 4. 번역투 (Translationese)

영어 문법을 한국어에 그대로 옮긴 표현. 학술 글에서 가장 자주 발생.

| 패턴 | 문제 | regex |
|---|---|---|
| `~에 의해 ~된다` | 영어 by의 직역 | `에\s+의해` |
| `~에 대한` (남발) | of/about/regarding의 직역. 풀어쓰기 | `에\s+대한` |
| `~을/를 통해` (남발) | through의 직역 | `을\s+통해|를\s+통해` |
| `~에 있어서` | in/at의 직역. 회피 | `에\s+있어서` |
| `~함에 따라` (남발) | 인과 표현. 적절한 위치만 | `함에\s+따라` |
| `~함에도 불구하고` | despite의 직역. "에도" 권장 | `함에도\s+불구하고` |

**임계치:** 한 단락에 `에 대한` ≥ 3 또는 `을/를 통해` ≥ 2면 경고.

**예:**
- ❌ "이 방법론에 대한 평가는 두 가지 데이터셋을 통해 진행된다."
- ✅ "이 방법론을 두 데이터셋에서 평가한다."

## 5. 메타 표현 / 자기언급 남용

| 패턴 | 문제 | regex |
|---|---|---|
| `~하고자 한다` (남발) | "하다"로 끝내도 충분 | `하고자\s+한다` |
| `~할 것이다` (의지 약함) | 평서로 단정 | `할\s+것이다` |
| `이를 통해` (남발) | 직전 문장 받기. 한 단락 ≤ 1회 | `이를\s+통해` |
| `상기` / `전술한` | 문어체 과잉. "위에서 본 / 앞서 말한" | `상기|전술한` |

### 5.1 "~하고자 한다" 비율 게이트 ★ NEW

연구계획서·제안서는 "~하고자 한다 / ~할 것이다 / ~하려 한다"가 마침표마다 반복되기 쉽다. 의도 표현은 필요하지만 **절반을 넘으면 글이 힘을 잃는다.**

```bash
# 절-종결 의도 동사 중 "~하고자 한다" 계열 비율
total=$(echo "$section" | grep -oE "(한다|하였다|했다|할 것이다|하고자 한다|하려 한다)\." | wc -l)
goja=$(echo "$section" | grep -oE "(하고자 한다|할 것이다|하려 한다)\." | wc -l)
# ratio = goja / total   →  > 0.5 fail,  목표 ≤ 0.3
```

- 섹션 단위 `~하고자 한다`+`~할 것이다`+`~하려 한다` 비율 **> 50%** → 표현축 fail. 절반 이상을 단정형("~한다 / ~했다")으로 바꾼다.
- 목표 **≤ 30%**. 계획·일정 단락은 거의 0%로 ("신청하고자 한다" → "신청한다"), 분석 절차는 "검토하고자 한다" → "검토한다", 연구 목표·기여만 한정적으로 "기여하고자 한다" / "기여할 수 있다".

## 6. 학술 글 forbidden phrases (스타일 차원)

| 표현 | 문제 |
|---|---|
| "이제 ~로 넘어간다" / "we now turn to" | 학술 글에선 미학적 X |
| "요약하면" / "in summary" (서두 X) | 결론에서만 사용 |
| "특기할 만한 점은" / "it is worth noting" | 모든 게 worth noting이면 아무것도 worth noting X |
| "또한" / "additionally" / "moreover" 남용 | 단순 나열 신호. 인과 명시 권장 |
| "최초로" / "for the first time" / "first attempt" | overclaim 위험 |
| "다양한" / "various" (서술 회피) | 구체적 종류 명시 |

## 7. 계사 대용 관용구 (Copula-substitute / placeholder predicate) ★ NEW

**가장 자주 보이는 한국어 "AI 티" 문형 중 하나.** "X는 Y이다"라고 단정하면 될 자리에 `장면 / 맥락 / 위치 / 자리 / 방향` 같은 빈 명사를 끼우고 `해당한다 / 위치한다 / 기능한다 / 자리매김한다`로 끝낸다. 추상도가 올라가고 행위 주체가 사라진다.

| 패턴 | ✗ 원문 | ✓ 권장 대체 | regex |
|---|---|---|---|
| `~에 해당한다` | "청소년 상담은 정신건강이 가시화되는 장면에 해당한다" | "~는 ~ 접점이다 / ~다" | `에\s+해당한다` |
| `~에 위치한다` / `~에 있다`(추상) | "메타분석도 같은 맥락에 위치한다" | "~도 이 흐름과 연결된다" | `(맥락|선상|연장선|위치)에\s+(위치한다|있다)` |
| `~로 기능한다` | "보완 자료로 기능할 수 있다" | "~로 활용될 수 있다 / ~로 쓰인다" | `(으)?로\s+기능한다|기능할\s+수\s+있다` |
| `~로 자리매김하다` | "표준적 절차로 자리매김하였다" | "~로 활용되어 왔다 / ~가 표준이 되었다" | `자리매김(하|해|했|되)` |
| `~방향에 있다` / `~방향에 위치한다` | "공백을 메우는 방향에 있다" | "~라는 문제의식에서 출발한다" | `방향에\s+(있다|위치)` |
| `핵심에 해당한다` / `핵심에 있다` | "혁신 축의 핵심에 해당한다" | "~가 혁신 축의 핵심이다 / 중요한 차별점이다" | `핵심에\s+(해당한다|있다)` |
| `~로 다루어져 왔다`(중복) + `~장면` | "주요 진입로로 다루어져 왔다" | 한 번만. 인접 단락 중복 시 패러프레이징 | — |
| `입력으로 기능한다` / `입력을 만든다` | "결과 정리의 직접적인 입력으로 기능한다" | "~의 핵심 자료가 된다 / ~에 쓰인다" | `입력으로\s+기능|입력을\s+만든다` |

**임계:** 섹션 전체에서 계사 대용 관용구 **≥ 3** → 자연스러움 게이트 -1. (자연스러움 누적 카운터에 1패턴=1로 합산하되, 같은 문장에 §4 번역투와 동시 등장해도 **이중 카운트하지 않는다** — 더 명백한 쪽 하나만 센다.)

**예:**
- ❌ "학교 안 상담은 그 중에서도 학생의 일상과 가장 근접한 접점에 해당한다."
- ✅ "학교 안 상담은 그중 학생의 일상에 가장 가까운 상담 접점이다."
- ❌ "SNS 회상 분석은 ... 편향을 부분적으로 분리하여 제시하는 보완 자료로 기능할 수 있다."
- ✅ "SNS 회상 분석은 면접 환경에서 가려질 수 있는 회상을 보완적으로 포착하는 자료원으로 활용될 수 있다."

## 8. 동족어·중복어 stacking (Cognate / duplicate-word piling) ★ NEW

한 문장(또는 인접 두 문장) 안에서 같은 한자어·어근이 두 번 이상 겹친다. "산출물을 산출한다", "연구의 연구 방법", "다시 재구성"(再=다시), "가능한 도달 가능한" 같은 형태. 읽는 사람이 즉시 어색함을 느낀다.

| 패턴 | ✗ 원문 | ✓ 권장 대체 |
|---|---|---|
| 동사-명사 동족어 | "두 산출물을 산출하고자 한다" | "두 산출물을 구축한다" |
| 인접 동족어 | "본 연구의 연구 방법은 ..." | "본 연구의 방법은 ..." |
| 接頭辭 중복 | "회상 표지 단위로 다시 재구성한 결과이다" | "회상 표지 단위로 재구성한 것이다" |
| 같은 부사 중복 | "가능한 도달 가능한 결론은 ..." | "이 절차를 통해 말할 수 있는 결론은 ..." |
| 같은 관형어 3중 | "동일한 매체, 동일한 시기, 동일한 자기보고 환경" | "같은 매체와 시기, 유사한 자기보고 환경" (의도된 강조 병렬이 아니면 압축) |

**검출 시그널:** 한 문장 안에서 같은 2자+ 한자어 어근이 2회↑ (`산출`, `연구`, `분석`, `통합`, `구성` 등), 또는 `다시 재-`, `미리 예-`, `함께 공-` 같은 한·고유어 중복.

**판정:** 문장당 동족어·중복어 stacking ≥ 1 = ✗ → 한쪽을 동의어로 바꾸거나 삭제. (의도된 anaphora/병렬은 예외 — "첫째 ~ 둘째 ~"처럼 구조적 반복은 OK.)

## 9. Register 불일치 (문어체 ↔ 구어체 혼재) ★ NEW

연구계획서는 한 가지 register를 유지해야 한다. 갑작스러운 **문어체**("아니한다", "상기", "전술한", "~에 다름 아니다")나 갑작스러운 **구어체**("끌려간 결과", "흔들림", "분포를 그려", "넓게 모은다", "막고", "가져온다", "옮긴다")가 섞이면 사람이 쓴 글로 보이지 않는다.

| 종류 | ✗ 원문 | ✓ 권장 대체 | regex |
|---|---|---|---|
| 갑작스런 문어체 종결 | "한 사건만으로 판정하지 아니한다" | "한 사건만으로 판정하지 않는다" | `아니한다|아니하며|아니하고` |
| 문어체 지시어 | "상기 절차 / 전술한 바와 같이" | "위 절차 / 앞서 말한 대로" | `상기\s|전술한` |
| 구어체 동사 (격식 문맥) | "분포가 특정 검색어에 끌려간 결과인지" | "분포가 특정 검색어에 과도하게 의존하는지" | `끌려간|흔들림|그려\b` |
| 구어체 동사 (격식 문맥) | "자료를 넓게 모은다 / 한계를 막고" | "자료를 폭넓게 수집한다 / 한계를 보완하고" | `넓게\s+모은다|막고\b` |
| 구어체 동사 (격식 문맥) | "절차의 큰 틀은 ~에서 가져온다 / 같은 흐름을 한국어에 옮긴다" | "분석 절차의 기본 구조는 ~를 참고한다 / 이 절차를 한국어 자료에 적용한다" | `가져온다|옮긴다\b` |

**판정:** 섹션 안에서 문어체·구어체 register 이탈 **합산 ≥ 2** → register 게이트 ⚠ → 한 register(학술 평서형)로 통일.

## 정량 grep 사용법

각 단락의 prose에 대해:

```bash
# 단어/패턴 카운트
echo "$paragraph" | grep -oE "것이다|것이며|수 있다" | wc -l
echo "$paragraph" | grep -oE "에 대한|에 의해|을 통해|를 통해" | wc -l
echo "$paragraph" | grep -oE "[가-힣]+적인|[가-힣]+적으로" | wc -l
```

Coach가 응답할 때:

```
이 단락에서:
- "것이다" 4개 (임계 3) → -1점
- "에 대한" 2개 (정상)
- 명사형 "-적인/-적으로" 3개 (임계 2) → -1점
표현 축 점수: 1/3
```

## 문장 길이·복잡도 점검 (선택)

| 지표 | 임계 |
|---|---|
| 한 문장 글자 수 | > 120자면 분해 검토 |
| 한 문장 동사 수 | > 3개면 분해 검토 |
| 안긴 절 깊이 | > 2 단계 분해 검토 |
| 한 문장 주어 개수 | 암묵 주어 포함 ≤ 2 |

이 지표들은 정확한 자동화는 어렵지만 Coach가 한 번씩 점검 트리거로 사용 가능.
