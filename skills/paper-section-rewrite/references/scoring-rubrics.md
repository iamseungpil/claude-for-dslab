# 채점 Rubrics

paper-section-rewrite와 academic-writing-trainer가 공유하는 채점표. 노션 4축(주제·내용·구성·표현)에 R1~R5 자동 점검 매핑.

---

## 4축 채점표 (각 1-3점)

### 축 1: 주제(의도)

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **명확성** | 글의 thesis가 모호 | 대체로 분명 | 1문장으로 정확히 lock |
| **적절성** | 장르·독자 미스매치 | 장르엔 맞음 | 장르·독자·범위 모두 정합 |
| **참신성** | 흔한 주장의 재진술 | 알려진 문제에 새 관점 | 실질적으로 새로운 발상 |

**축 합계 0-9점.** Stage 1·0.5 통과 임계: **7/9.**

### 축 2: 내용

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **풍부함** | 근거 빈약 | 충분한 근거 | 사실 논거 + 적절한 소견 논거 결합 |
| **구체성** | 추상 일변도 | 일부 구체 사례 | 고유명·수치·인용 모두 갖춤 |
| **통일성** | 주제 이탈 | 대체로 통일 | 모든 supporting point가 thesis 직결 |

**축 합계 0-9점.** Stage 2 통과 임계: **6/9.**

### 축 3: 구성

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **짜임새** | 단락 배열 무질서 | 큰 흐름 보임 | 단락별 역할 명확, 장르 의무 단락 충족 |
| **간결 구조화** | 같은 내용 중복 | 큰 중복 없음 | 단락 budget 효율적 사용 |
| **핵심 추출** | 핵심 묻힘 | lead만 봐도 흐름 추정 가능 | lead들만 읽어도 글 전체 메시지 명확 |
| **논리 연결** | 문단 간 연결 끊김 | 인접 인과 통함 | 모든 인접 단락 인과 명시적 |

**축 합계 0-12점.** Stage 3 통과 임계: **9/12.**

### 축 4: 표현

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **의미 정확** | 모호한 문장 다수 | 대체로 명확 | 모든 문장 일의적 |
| **어휘 자연** | 번역투/한자어 과잉 | 대체로 자연스러움 | 한국어다움 + 학술 register |
| **문법** | 주술 불일치/비문 | 큰 비문 없음 | 모든 문장 문법 정합 |
| **금지어** | 임계치 다수 초과 | 1-2 초과 | 모든 임계 통과 |

**축 합계 0-12점.** Stage 4 통과 임계: **9/12.** Stage 5 통과 임계: **10/12.**

---

## R1~R5 자동 점검 (Stage 3 핵심)

| R | 패턴 | 점검 방법 | fail 시 |
|---|---|---|---|
| **R1** | 장르 라벨링 + 의무 단락 정의 | 사용자가 장르 라벨 입력 → genre-rubrics에서 의무 단락 인출 | Stage 0.5에서 라벨 강제 |
| **R2** | 의무 단락 누락 | 각 lead에 단락 역할 라벨 강제 → 의무 단락에 라벨 0개면 누락 | **fail-fast (구성 축 즉시 1점)** |
| **R3** | 흐름 역전 | 인접 lead의 인과 검사 (한계→제안 정상; 제안→한계 역전) | 구성 축 -1, 위치 지정 코멘트 |
| **R4** | 인접 단락 중복 | 인접 lead 의미 유사도 (cosine 또는 Coach 직관) | 구성 축 -1, "분리 불필요" 코멘트 |
| **R5** | thesis 정렬 | 각 lead가 Stage 2 content sentence를 어떻게 지지하는지 한 줄 라벨 | 라벨 못 다는 lead → 잉여 경고 |

R2는 **즉시 fail-fast**. 다른 점수와 무관하게 통과 불가.

## 통과 임계치 표 (전체 lock)

| Stage | 점수 만점 | 통과 임계 | 비고 |
|---|---|---|---|
| Stage 0.5 (장르 라벨) | 통과/실패 | 라벨 1줄 작성 | 점수 없음 |
| Stage 1 (의도 1문장) | 9 (주제축) | **7** | 7 미만이면 재시도 |
| Stage 2 (내용 1문장) | 9 (내용축) | **6** | 의도 정합도 보너스 가능 |
| Stage 3 (5 leads) | 12 (구성축) + R 점검 | **9 + R2 통과** | R2 fail은 즉시 NEEDS_WORK |
| Stage 4 substage (문단) | 12 (4축 통합) | **9** | 모든 단락 substage 동일 임계 |
| Stage 5 (통합) | 12 + 전체 일관성 | **10** | 가장 엄격 |

## Pass/Fail 게이트 (paper-section-rewrite v4 4-Level critic loop) ★

paper-section-rewrite는 점수 외에 **Pass/Fail 게이트**를 4 Level + 통합·감사에서 운용한다. 한 게이트라도 ✗면 그 Level은 NEEDS_WORK이며, 모두 ✓일 때만 다음 Level로 진행.

### Level 1 — 내용

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| 의도 1문장 명확성 | 동사 lock + 1문장 | 재추출 |
| 내용 1문장 정합 | 의도와 supporting 관계 | 재정의 |
| **Insight-first** ★ | "what 나열" → "why 명시" 완료 | lead의 WHY 절 추가 |
| R5 thesis 정렬 | 도구가 아닌 방법·결과 자체가 thesis | thesis 재명명 |

### Level 2 — 문단 간 구성

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| R1·R2 | 장르 라벨 + 의무 단락 누락 0 | 단락 신설 |
| R3 | 인접 흐름 역전 0 | 단락 순서 재배열 |
| R4 | 인접 단락 중복 0 | 두 단락 통합 |
| R5 | 모든 lead가 thesis 지지 | 잉여 lead 제거 |
| **결과 섹션 흐름** ★ | 의도→방법→결과→해석 (해당 장르) | lead 재배치 |
| **Insight-first lead** ★ | 모든 lead가 insight 제시 | "왜 새로운지" 절 추가 |

### Level 3 — 문단 내 구성

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| 카테고리 흐름 일치 | 모든 단락 역할 정합도 ≥ 4/5 | 문장 추가/제거/이동 |
| 의무 카테고리 충족 | 단락별 의무 카테고리 모두 등장 | 누락 카테고리 문장 신설 |
| 잉여 회피 제거 | 회피 카테고리 0 또는 단락 역할에 합당 | 다른 단락으로 이동 |

### Level 4 — 문장

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| **단문 (One Role)** ★ | 모든 문장 단일 카테고리 | 두 문장으로 분할 |
| **단문 비율** ★ NEW | 단락당 단문(KO 50자/EN 20w) 비율 ≥ 60% | 긴 문장 분할·압축 |
| **자연스러움** ★ | 단락당 AI tell 패턴 누적 < 3 | 직접 단정문·자연 접속어로 재작성 |
| **논리적 비약** ★ | 단락당 비약 0 | 중간 추론 한 문장 추가 |
| **ML-beginner** ★ | lead·본문 4개 항목 통과 (약어 풀어쓰기 / 수식 전 자연어 / jargon ≤ 3 / **서술형 풀어쓰기 — 명사형 종결 X**) | 풀어쓰기·분리·서술형 변환 |
| 정량 grep | 모든 banned-phrase 임계 통과 | 표현 재작성 |
| 4축 통합 | 9/12 이상 | 미달 항목 보완 |

### Phase 5 — 섹션 통합

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| **자기 완결성** ★ | 섹션 참조 ≤ 2 | 자기 완결 1줄 요약 패러프레이징 |
| **섹션 간 중복** ★ | 동일 표현 0 | 패러프레이징 (역할 분담) |
| 4축 종합 | 38/42 이상 | 미달 항목 punch list |

### Phase 6 — 본문+부록 수식·notation 감사

| 게이트 | 통과 조건 | 위반 시 |
|---|---|---|
| 심볼 first-use 정의 | Orphan 0 | 정의 추가 또는 심볼 제거 |
| 심볼 혼용 | 같은 letter 두 의미 X | 부록 심볼 변경 |
| 첨자·서식 컨벤션 | `x_i` vs `x_{i}` 등 일관 | 일관 표기로 통일 |
| Cross-reference | 깨짐 0 | 참조 수정 |
| Body vs Appendix | 동일 정의 | 본문 정의로 통일 |
| **수식 오용 (Misuse)** ★ | 본문 설명 ↔ 수식 mismatch 0 | 수식 또는 본문 보정 |
| **단위 일관** ★ | 시간·확률·토큰 단위 일관 | 한 단위로 통일 |
| **Orphan equation** ★ | 본문에서 한 번도 안 가리키는 등번호 0 | 참조 추가 또는 등번호 제거 |

**판정 규칙**: 한 게이트라도 ✗면 해당 Phase는 NEEDS_WORK. 모든 게이트 ✓ + 점수 임계 통과 = CONVERGED. critic loop는 최대 3 라운드.

## 채점 Coach 출력 템플릿

매 round 다음 형태로 출력:

```
잘 된 점:
  [강점 1가지 명명]

개선점:
  [가장 큰 개선점 1가지]
  → 원칙: [R 라벨 또는 축 항목]

점수:
  주제 X/9 (명확 1, 적절 1, 참신 1)
  내용 X/9 (풍부 1, 구체 1, 통일 1)
  구성 X/12 (짜임 1, 간결 1, 핵심 1, 논리 1) | R2/3/4/5 점검: ...
  표현 X/12 (정확 1, 자연 1, 문법 1, 금지어 1) | grep: 것이다 N개 / 에 대한 N개

다음 행동:
  [한 가지만 제시 — 통과까지 가장 빠른 길]
```

## 점수 추이 시각화

매 substage 종료 후:

```
문단 3 (제안) — 시도 진행
─────────────────────────
시도 1: 7/12  □□□□□□□░░░░░  (통일 2 / 연결 1 / 완결 2 / 표현 2)
시도 2: 9/12  □□□□□□□□□░░░  (통일 3 / 연결 2 / 완결 2 / 표현 2)  ✓ 통과
```

ASCII 막대 그래프로 진보 가시화. Coach가 항상 시도 사이 점수 변화를 명시: "지난번보다 +2".

## 학습 리포트 (Stage 5 종료 시)

```
─── 학습 리포트 ───
완성도: 평균 X.X / 12

자주 잡힌 패턴 TOP 3:
1. R3 흐름 역전 — N회 (단락 X, Y에서)
2. 금지어 "것이다" — 단락 1: A개 → 단락 5: B개 ★ 개선 추이
3. 명사형 누적 — 평균 N/문장

다음에 또 같은 종류의 글을 쓸 때 의식하면 좋을 것:
- [개인화된 권고 1-3개]

체화도(같은 패턴이 줄어든 비율): X%
```

이 리포트가 학습의 가시화. 다음 세션에서 reference로 사용 가능.
