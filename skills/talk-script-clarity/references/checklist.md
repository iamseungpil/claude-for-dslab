# Talk Script Clarity — 장별 체크리스트

발표 전체에 한 번(①②), 장마다 한 번(③~⑦), 마지막에 통독 한 번(⑥) 본다.

## 발표 전체

- [ ] ① 한 문장 주제가 첫 장(첫 1분)에 있다
- [ ] ① 결론 장과 마지막 장에서 같은 주제 문장을 거의 같은 말로 회수한다
- [ ] ① 장별 한 줄 요약을 이으면 주제 문장이 된다
- [ ] ② 큰 은유 하나가 정해져 있다
- [ ] ② 은유 회수 지도: 심기 → 이름 붙이기 → 중간 회수 → 결론·마지막 장 회수
- [ ] ② 은유가 사라지는 구간이 전체의 1/3을 넘지 않는다

## 장마다

- [ ] ③ (핵심 주장 장이라면) 청중이 10초 안에 떠올릴 예제·비유가 데이터보다 먼저 나온다
- [ ] ④ 말하는 숫자가 주장당 하나(많아야 대비 한 쌍), 장당 8개 미만
- [ ] ④ 어림말로 바꾼 숫자의 방향과 크기가 원래 값과 맞다
- [ ] ⑤ 약어·전문 용어는 처음 나올 때 쉬운 말이 붙어 있다
- [ ] ⑤ 같은 대상을 다른 이름으로 부르지 않는다(논문 용어와 연결은 발표 전체에서 한 번)
- [ ] ⑥ 여러 개를 말할 때 개수를 먼저 말한다
- [ ] ⑥ 마지막 문장이 다음 장의 질문을 연다
- [ ] ⑦ 짧은 문장(≤ 50자) 비율 ≥ 60%, 짧은 문장만 넷 이상 연속은 없다
- [ ] 그림 방향어("왼쪽", "빨간 선")가 실제 슬라이드와 맞다
- [ ] 작업 경과 표현(리뷰 대응, 다시 돌린, 수정본에서)이 없다
- [ ] `[초]` 표기가 글자 수와 맞다(약 5~5.5자/초)

## 결론 장

- [ ] ⑦ 발표에서 문장이 가장 짧다
- [ ] ① 주제 문장 앞에 "(잠시 멈춤)"이 있다
- [ ] ② 큰 은유로 닫는다

## 통독(순서 변경·장 합치기 뒤 필수)

- [ ] 장 경계에서 같은 접속어("그런데", "그래서")가 연달아 나오지 않는다
- [ ] 앞 장에서 이미 한 설명을 다음 장이 되풀이하지 않는다(주제 문장·은유 반복은 예외)
- [ ] 앞에서 나온 숫자를 다시 말할 때 "앞에서 본"으로 받는다
