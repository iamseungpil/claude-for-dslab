# 전후 예시 — RSP 랩세미나 대본

50장, 약 36분짜리 랩세미나 대본(Random Soft Prompt, 학습 없는 무작위 벡터로 추론의 첫 갈림길을
넓히는 연구)에 이 스킬을 적용한 기록이다. 사실과 수치는 그대로 두고 말하는 방식만 고쳤다.

## 측정 요약

`scripts/clarity_metrics.py`로 잰 값이다(부록 포함 61장, `--metaphor 함정`).

| 항목 | 전 | 후 |
|---|---|---|
| 말하는 숫자 합계 | 155 | 132 |
| 숫자 8개 이상인 장 | 18, 38, 42, 43 | 30, 38 (30은 메뉴 번호·순위 표기라 실제 수치는 둘) |
| 짧은 문장(≤ 50자) 비율 | 77% | 82% |
| 짧은 문장 60% 미만인 장 | 2, 14, 20, 32, 34, 42, 43, 50 (+부록 2) | 부록 2장만 |
| 풀지 않은 전문 용어 | 로짓 간격, 항진식, 순위 상관, 은닉 상태, 상한 | 0 |
| 은유("함정") 등장 장 | 없음 | 1, 10, 11, 13, 23, 30, 37, 42, 45, 46, 50 |
| 장 머리말 시간 합계 | 37분 20초 | 36분 50초 |

측정 플래그는 판단 재료다. 예를 들어 18장의 "다섯 번을 다시 돌려도"는 반복 실험을 설명하는 말이라
작업 이력이 아니지만 HISTORY로 잡힌다. 30장의 숫자는 대부분 순위 이름이다.

## 은유 회수 지도 (원칙 2)

| 장 | 역할 | 대본 속 표현 |
|---|---|---|
| 1 | 심기 | 언어 모델은 자꾸 같은 함정에 빠진다 |
| 10 | 이름 | 저는 이걸 pitfall, 함정이라고 부른다 |
| 11 | 처방 연결 | 함정 앞에서 길을 흔들어 다른 길을 연다 |
| 13 | 사례 예고 | 같은 함정에 열여섯 번 빠졌다 |
| 23 | 기전 | 함정으로 가는 길 하나 대신 여러 길이 열린다 |
| 30 | 비교 | 온도를 올려도 같은 함정 입구로 들어간다 |
| 37 | 시점 | 함정은 입구에서 갈리니까 입구에서만 흔들면 된다 |
| 42 | 사례 회수 | 열여섯 번 모두 같은 함정이었다 |
| 45 | 결론 | 함정으로 들어가는 첫 갈림길이 넓어진다 / 함정에 빠졌는지조차 안 보인다 |
| 46, 50 | 마무리 | 함정 앞에서 길을 열었다 / 익숙한 함정에 끌려가는 모델도 |

## 원칙 3 — 머릿속에서 풀어 볼 비유

전:
> 다양성 하면 보통 온도부터 떠올리시죠. 왼쪽이 온도를 2로 올린 경우입니다. 막대는 평평해지는데,
> 동그라미 속 순위는 1부터 5까지 그대로예요.

후:
> 다양성 하면 보통 온도부터 떠올리시죠. 식당 메뉴판에 빗대 보면, 온도를 올리는 건 메뉴판 글씨를
> 흐리게 하는 겁니다. 다른 메뉴가 골라질 확률은 늘지만, 1번 메뉴는 여전히 1번이죠. (…) RSP는
> 메뉴판 순서 자체를 섞습니다.

## 원칙 4 — 주장 하나에 숫자 하나

전(숫자 15개):
> 표에서 온도를 2나 3으로 올려도 순위 상관은 1 그대로입니다. RSP는 0.71로 실제로 순서를 바꾸고요.
> (…) AIME24에서 열여섯 번 중 한 번이라도 맞힌 비율이, 온도 1은 20%, 1.5는 23%, RSP는 37%였습니다.

후(숫자 11개, 대비 두 쌍만):
> 온도는 2나 3으로 올려도 순서가 그대로입니다. RSP는 실제로 순서를 바꾸고요. 대가도 다릅니다.
> (…) 온도 3은 정확도가 1%대로 무너지고 RSP는 73%를 지킵니다. 그리고 (…) 온도 1은 20%,
> RSP는 37%였습니다.

전(설정 숫자 나열):
> OpenR1-Math에서 네 번 풀려서 많아야 한 번 맞히는 문제만 골랐는데, 3만 2천 개 정도 됩니다. 문제마다
> 여덟 번씩 풀려서 맞은 풀이만 모았더니, RSP는 이 문제들의 49.7%에서 (…) 기본 모델은 23.8%였어요.
> 2.1배죠.

후:
> 기본 모델이 거의 못 푸는 문제만 골라서 맞은 풀이를 모았더니, RSP가 정답 풀이를 건진 문제가 기본
> 모델의 2.1배였어요.

## 원칙 5 — 용어 풀기, 이름 하나

| 전 | 후 |
|---|---|
| 이 상한을 정하는 점수 차, 로짓 간격이 | 이 최대치를 정하는 점수 차가 |
| 식이 항진식으로 무너지니까 | 늘 참인 식만 나와서 아무것도 알 수 없으니까 |
| 첫 토큰 순위 상관이 온도는 1, RSP는 0.71 | 순서가 얼마나 그대로인지를 재 보면, 1이면 하나도 안 바뀐 건데, 온도는 1, RSP는 0.71 |
| SAE라는 도구로 | 희소 오토인코더, 줄여서 SAE라는 도구로 |
| (주입·붙이기·끼워 넣기 혼용) | 논문에서는 주입이라고 하는데, 오늘은 계속 붙이기라고 부를게요 |

## 원칙 6 — 이음새 (장 순서를 바꾼 뒤)

전: 15장이 "그런데 정말 그럴까요?"로 끝나고, 16장이 "그런데 MemGen을 직접 돌려 보다가…"로 시작하며
15장 구조 설명을 되풀이.

후: 16장 첫 문장을 "그래서 직접 해 봤습니다. 위쪽이 방금 본 구조를 간단히 그린 거고요,"로 줄였다.

## 원칙 7 — 결론 장

전(문장 평균 44자):
> 학습 안 한 무작위 벡터가 어텐션 경로를 흔들면, 그것만으로 추론의 첫 갈림길이 넓어진다. 크기는 w가,
> 방향은 등방 분포가, 끝나는 시점은 문맥의 성장이 정했고, 학습한 방법과 비슷한 성능까지 갔죠.

후(문장 평균 31자):
> 오늘 이야기를 한 문장으로 줄이면 이렇습니다. (잠시 멈춤) 학습 안 한 무작위 벡터를 붙이면, 함정으로
> 들어가는 첫 갈림길이 넓어집니다. 얼마나 흔들지는 w가 정합니다. 어느 쪽으로 흔들지는 등방 분포가
> 정합니다. 언제 멈출지는 문맥이 자라면서 알아서 정하죠.
