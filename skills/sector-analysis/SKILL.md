# Sector Analysis — 내러티브 기반

## 핵심 철학: 왜 이 섹터인가?

**모든 분석은 "왜"로 시작한다:**

| 질문 | 역할 |
|------|------|
| **왜 이 섹터가 성장하는가?** | 수요의 원천 (정책/기술/소비 변화) |
| **왜 지금인가?** | 티핑 포인트, 촉매 이벤트 |
| **왜 이 기업들인가?** | 밸류 체인 내 핵심 노드 + 지배 기업 |

---

## 두 가지 접근법

### A. RSI 스크리닝 (숫자 기반)

**프로세스:**
```
RSI 70+ 종목 필터링 → 섹터 클러스터링 → 왜 이 섹터에 자금 집중? → 심층 분석
```

**RSI(상대강도지수)**: 14일 기준, 70 이상이면 강한 상승 모멘텀

**해석 주의:**
- RSI 70+ = 무조건 과열 ❌
- RSI 70+ = "왜 자금이 몰리는지" 조사 신호 ✅

### B. 내러티브 기반 (정책/테마)

**프로세스:**
```
테마 선정 → 밸류 체인 매핑 → 핵심 노드 식별 → 노드별 지배 기업 → 분석 실행
```

**정책 드라이버 예시:**

| 정책 | 수혜 섹터 | 핵심 질문 |
|------|----------|----------|
| CHIPS Act | 반도체 제조, 장비 | 미국 내 팹 건설 수혜자는? |
| IRA | 청정에너지, EV | 세액공제 조건 충족 기업은? |
| America First | 방산, 인프라 | 리쇼어링 최대 수혜자는? |

**미래 산업 테마:**

| 테마 | 밸류 체인 핵심 노드 |
|------|-------------------|
| AI | GPU 설계, 파운드리, HBM 메모리 |
| 자율주행 | 센서(LiDAR), 소프트웨어, 반도체 |
| 로보틱스 | 액추에이터, 센서, AI 칩 |
| 우주 | 발사체, 위성, 지상 인프라 |
| 에너지 | SMR, 그리드, ESS |

## 섹터 분석 프로세스

### Step 1: 테마/정책 출발점

**검증 질문:**
- 예산 규모는? 시행 시점은?
- 수혜 조건은? (예: IRA 세액공제 요건)
- 이 트렌드가 5년 후에도 유효한가?

### Step 2: 밸류 체인 매핑

**예시 — AI 테마:**
```
[설계/IP] → [제조] → [패키징] → [메모리] → [시스템] → [클라우드] → [앱]
    │          │         │          │          │          │          │
  NVIDIA     TSMC     Amkor    SK하이닉스    Dell       AWS      OpenAI
  AMD        삼성      ASE      Micron     Supermicro  Azure    Anthropic
  ARM                                      HPE         GCP
```

**예시 — 반도체 리쇼어링 (CHIPS Act):**
```
[팹 건설] → [장비] → [소재] → [제조] → [후공정]
    │         │        │        │         │
  건설사    ASML    Entegris   Intel    Amkor
          AMAT     Linde    TSMC(AZ)
          Lam      Air Liquide
          KLA
```

### Step 3: 핵심 노드 식별

**평가 기준 (각 0-3점):**

| 기준 | 질문 |
|------|------|
| 병목 | 이 노드가 막히면 전체 체인 멈춤? |
| 대체 불가 | 다른 플레이어로 교체 어려움? |
| 마진 집중 | 이익이 여기에 집중? |
| 레버리지 | 테마 성장 시 최대 수혜? |

**8점 이상 = 핵심 노드 ⭐**

**예시 — AI 밸류 체인:**

| 노드 | 병목 | 대체불가 | 마진 | 레버리지 | 합계 |
|------|------|---------|------|---------|------|
| GPU 설계 | 3 | 3 | 3 | 3 | **12** ⭐ |
| 파운드리 | 3 | 3 | 2 | 2 | **10** ⭐ |
| HBM 메모리 | 3 | 2 | 2 | 3 | **10** ⭐ |
| 클라우드 | 2 | 1 | 2 | 2 | 7 |

### Step 4: 노드별 지배 기업 선정

**선정 기준:**
- 시장 점유율 1-2위
- 기술 리더십 (차세대 기술 선도)
- 재무 건전성 (투자 여력)
- 수직 통합 (밸류 체인 내 추가 지배력)

### Step 5: 분석 우선순위 결정

```
             핵심 노드          일반 노드
           ┌─────────────┬─────────────┐
  1위 기업 │  🔴 필수    │  🟡 권장    │
           ├─────────────┼─────────────┤
  2위 기업 │  🟡 권장    │  🟢 선택    │
           ├─────────────┼─────────────┤
  3위 이하 │  🟢 선택    │  ⚪ 제외    │
           └─────────────┴─────────────┘
```

## 섹터 분석 보고서 구조

### 1. Executive Summary
- **한 문장 섹터 정의**: "[섹터]는 [문제]를 해결하는 산업이다"
- 왜 지금 이 섹터인가? (촉매)
- 핵심 투자 논지

### 2. 수요의 원천: 왜 이 섹터가 성장하는가? ⭐ 핵심

**반드시 "왜"로 시작:**
- 어떤 문제가 해결되고 있는가?
- 정책/기술/소비 변화 중 무엇이 드라이버인가?
- 일시적 vs 구조적 성장 판별

```
예시 — 반도체 장비:

문제: 미국 반도체 자급률 12%, 지정학 리스크
정책: CHIPS Act $527억 + 25% 세액공제
결과: 미국 내 팹 건설 붐 → 장비 수요 폭발
구조적?: Yes, 공급망 안보는 장기 트렌드
```

### 3. 산업 구조

**3.1 밸류 체인 맵** — 시각화 필수
**3.2 경쟁 강도** (Porter's 5 Forces 요약)
**3.3 진입 장벽**

### 4. 주요 플레이어 분석

| 기업 | 노드 | 점유율 | 강점 | 약점 |
|------|------|--------|------|------|
| ASML | 장비(EUV) | 100% | 독점 | 지정학 |
| AMAT | 장비(증착) | 20% | 다각화 | 경쟁 |

**포지셔닝 맵** (2x2 매트릭스) 권장
