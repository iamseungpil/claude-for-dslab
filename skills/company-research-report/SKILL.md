# Company Research Report — 내러티브 중심

## 핵심 철학: 왜 → 무엇을 → 어떻게

모든 섹션은 세 가지 질문으로 구성:

| 질문 | 역할 | 예시 |
|------|------|------|
| **왜** | 수요의 원천, 존재 이유 | "왜 고객이 돈을 내는가?" |
| **무엇을** | 구체적 사업/제품 | "어떤 제품으로 매출을 만드는가?" |
| **어떻게** | 실행 방식, 경쟁 우위 | "왜 경쟁사가 아닌 이 회사인가?" |

**❌ BAD**: "NVIDIA는 AI GPU를 만들고, 데이터센터 매출이 88%다"

**✅ GOOD**: "AI 모델 학습에는 수조 번의 병렬 연산이 필요하다. CPU는 순차 처리하지만 GPU는 수천 코어가 동시에 연산한다. GPT-4를 CPU로 학습하면 수십 년, NVIDIA GPU로는 수 주. 이것이 하이퍼스케일러들이 NVIDIA에 수백억 달러를 쏟는 이유다. AI 경쟁에서 뒤처지면 사업이 위협받기 때문이다."

---

## 전문 용어 해설 규칙 (필수)

**3단계 해설 체계:**

| 단계 | 위치 | 방식 | 예시 |
|------|------|------|------|
| 즉시 해설 | 용어 첫 등장 | 괄호 내 정의 | "PEG(P/E를 이익성장률로 나눈 값, 1 미만이면 저평가 가능)" |
| 맥락 해설 | 숫자 언급 시 | 비교/의미 | "75%는 업계 평균(40-50%)의 2배로, 가격 결정력이 강하다는 의미" |
| 용어집 | 보고서 끝 | 가나다순 | 전체 전문용어 + 상세 설명 |

## 필수 섹션 구조

### 1. Executive Summary
- **한 문장 포지션**: "이 회사는 [산업]의 [역할]이다"
- 왜 지금 주목해야 하는가?
- 핵심 투자 논지 3줄 요약

### 2. 수요의 원천: 왜 이 사업이 필요한가? ⭐ 핵심

**반드시 "왜"로 시작. 가장 중요한 섹션.**

- 고객이 해결하려는 문제는 무엇인가?
- 왜 이 회사의 제품이 그 문제를 푸는가?
- 왜 대안이 아닌 이 회사인가?

```
예시 — NVIDIA:

고객의 문제: AI 모델 학습에 엄청난 연산량 필요
해결책: GPU의 병렬 연산 (CPU 대비 100배 빠름)
왜 NVIDIA: CUDA 생태계 20년 축적, 전환비용이 수백만 달러
```

### 4. 산업 내 포지션

**4.1 밸류 체인 위치**
```
[설계] → [제조] → [패키징] → [시스템] → [클라우드] → [앱]
   │        │         │          │          │          │
 NVIDIA   TSMC     Amkor       Dell       AWS      OpenAI
```

**4.2 경쟁 구도**: 누가 같은 파이를 노리는가?

**4.3 한 문장 포지션**: "이 회사는 [밸류체인]에서 [역할]을 하며, [이유]로 대체 불가능하다"

### 5. 경제적 해자 (4가지 모두 검토)

| 해자 유형 | 핵심 질문 |
|----------|----------|
| 전환비용 | 고객이 떠나기 어려운가? 왜? |
| 네트워크 효과 | 사용자가 늘수록 가치 증가? |
| 무형자산 | 브랜드/특허/규제 장벽? |
| 원가우위 | 경쟁사보다 싸게 만드는가? |

**5.5 종합 평가**: 해자 넓이, 지속 가능성, 주요 위협

### 6. 기업 역사

- 6.1 창업과 초기 비전: 어떤 문제를 풀려 했는가?
- 6.2 핵심 전환점: 어떤 결정이 오늘의 위치를 만들었는가?
- 6.3 최근 변화

### 7. 경쟁 승리 스토리

- 과거에 어떤 경쟁자를 어떻게 이겼는가?
- 그 승리 요인이 현재까지 유효한가?
- 새로운 위협은?

### 8. 미래 전망

- 8.1 성장 동력: 무엇이 매출을 끌어올리는가? **왜?**
- 8.2 핵심 리스크: 무엇이 스토리를 무너뜨릴 수 있는가?

### 9. Bull / Bear / Base Case — 🔷 추세선 그래프 필수

**내러티브 기반 예측: 전제 → 논리적 연쇄 → 결과**

각 시나리오는 앞서 작성한 내러티브(수요 원천, 해자, 리스크)에서 논리적으로 도출.

```
Bull Case 예시:

전제: AI 투자 사이클이 2027년까지 지속
논리: 하이퍼스케일러 설비투자 6,000억 달러 → Blackwell 2.2배 성능으로 
      교체 수요 → CUDA 해자가 경쟁 방어
결과: 데이터센터 매출 연 25% CAGR → 2030년 $3,500억
```

**추세선 그래프**: `references/trendline_guide.md` 참조
