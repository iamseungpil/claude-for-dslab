# Stage 5 — 통합 양식

5개 단락(또는 모든 섹션)을 합쳐서 전체 문서로 다듬기.

## 채점 기준 (만점 12, 통과 10)

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **전환** | 단락 간 점프 | 대체로 자연스러움 | 모든 인접 단락 접속어 정합 |
| **일관성** | 용어·표기 흔들림 | 큰 문제 없음 | 완전 일관 |
| **균형** | 분량 극심한 불균형 | 대체로 균형 | budget 정합 |
| **호응** | 도입↔결론 미스매치 | 부분 호응 | 완전 호응 (thesis 회수) |

## 전환 점검

인접 단락 사이의 접속어가 단락의 인과 관계와 맞아야:

| 인과 관계 | 권장 접속어 |
|---|---|
| 한계 → 해법 | 그래서 / 따라서 / 이를 위해 |
| 동기 → 한계 | 그러나 / 그런데 / 한편 |
| 제안 → 차별성 | 특히 / 이는 / 이렇게 |
| 차별성 → 평가 | 본 연구는 / 이 프레임워크를 |
| 일반 진술 → 예시 | 예를 들어 / 구체적으로 |

## 일관성 점검

| 점검 | 대상 |
|---|---|
| 용어 통일 | 같은 개념을 다르게 부르지 않기 (예: "사용자 궤적" vs "유저 trajectory") |
| 약어 도입 순서 | 첫 등장에서만 정의, 이후 약어만 |
| 시제 통일 | 본 연구 X한다 (현재) vs X했다 (과거) 혼용 X |
| 인칭 통일 | "본 연구는" / "we" 일관 |

## 균형 점검

5문단의 각 단락 분량이 다른 단락의 2배 이상이면 경고.

| 단락 | 분량 (문장 수) | 비고 |
|---|---|---|
| 1. 배경 | | |
| 2. 한계 | | |
| 3. 제안 | | |
| 4. 차별성 | | |
| 5. 평가 | | |

가장 길어도 가장 짧은 것의 2배 이내.

## 호응 점검

- 도입 thesis (단락 1 또는 1+2 lead)
- 결론 contribution (단락 5 lead)

이 둘이 같은 thesis를 다르게 표현하고 있는가?
