# Stage 4 — 한 문단 prose 작성 양식

지정된 단락 1개의 prose 작성. 권장 분량 3-5문장.

## 채점 기준 (만점 12, 통과 9)

| 항목 | 1점 | 2점 | 3점 |
|---|---|---|---|
| **통일성** (unity) | 주제 흐트러짐 | 대체로 통일 | lead와 모든 문장 한 주제 |
| **연결성** (coherence) | 문장 배열 어색 | 대체로 순리적 | 인접 문장 인과 명시적 |
| **완결성** (completeness) | lead 뒷받침 부족 | 적절한 뒷받침 | 충분하고 정확한 뒷받침 |
| **표현** | 문법·금지어 다수 | 큰 문제 없음 | 모든 임계 통과 |

## 문단 작성 원칙 (Notion 3주차)

### 1. 두괄식 (디폴트)

첫 문장 = 그 단락의 thesis = lead sentence.
이후 문장은 그 lead를 풀어/뒷받침/예시.

```
[Lead 첫 문장]. [뒷받침 1]. [뒷받침 2]. [예시 또는 결론 문장].
```

### 2. 통일성

**나쁜 예:**
> 사물의 상태가 적정한 도(道)를 넘어서면 문제가 된다. 우리말에서는 이러한
> 상태에 대해 과(過)하다고 한다. 곧 과도하다는 말이다. ... 이렇게 과한 상태는
> 안정된 상태가 아니다. 그것은 불안정하며, 따라서 문제 상황이 되고 피해를
> 가져온다. **과격하거나 과민한 행동은 저항을 불러오며, 누르는 힘이 과하면
> 굽혀지기보다 부러진다.** ← 갑자기 새 주장 등장 (통일성 위반)

### 3. 연결성

**나쁜 예 (접속어 없음):**
> 자연은 물리적으로 알 수 있는 물질덩어리이며, 인간만이 ... 서양의 자연관은
> 한마디로 이원론이다. 20세기에 확립된 상대성 이론이나 양자역학에서는...
> "빛이 파동인가 입자인가?"라는 물음...

**좋은 예 (접속어 + 두괄식):**
> **서양의 자연관은 한마디로 이원론이다.** 자연은 물리적으로 알 수 있는
> 물질덩어리이며, 인간만이 ... **그러나** 20세기에 확립된 상대성 이론이나
> 양자역학에서는 ... **예를 들어,** "빛이 파동인가 입자인가?"라는 물음에 대해...

### 4. 완결성

소주제문 + 충분한 뒷받침. 너무 짧으면 fail.

## 정량 grep (Coach 자동)

매 round Coach가 다음 점검:

| 패턴 | 임계 | 예시 |
|---|---|---|
| 것이다 / 것이며 / 수 있다 | ≥ 3개/단락 → -1 | "학습한 것이다" → "학습한다" |
| 에 대한 | ≥ 3개/단락 → -1 | "X에 대한 평가" → "X를 평가" |
| 명사형 (-적인/-적으로) | ≥ 3개/단락 → -1 | "효율적인 X" → "효율 좋은 X" |
| 됩니다 / 되어진다 / 지게 된다 | 0 권장 | "평가됩니다" → "평가한다" |
| em-dash (—) | 0 강제 | 괄호·세미콜론으로 대체 |

