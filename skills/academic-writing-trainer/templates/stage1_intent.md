# Stage 1 — 의도 1문장 작성 양식

이 글이 무엇을 하려는지 1문장으로 적어주세요.

## 채점 기준 (만점 9, 통과 7)

- 명확성: 모호 1 / 대체로 분명 2 / 1문장으로 정확히 lock 3
- 적절성: 장르·독자 미스매치 1 / 장르엔 맞음 2 / 장르·독자·범위 모두 정합 3
- 참신성: 흔한 재진술 1 / 새 관점 2 / 실질적 새 발상 3

## 권장 구조

```
본 [연구/논문/리포트]는 [목적어]를 [동사]한다.

동사 옵션:
- 제안한다 (방법론·모델 도입 시)
- 보인다 / 입증한다 (결과·정리 시)
- 분석한다 (현상 설명 시)
- 보고한다 (실험 데이터 정리 시)
- 비평한다 (논평 시)
```

## 예시

KO:
> 본 연구는 사용자 궤적 데이터를 활용해 인공지능의 일반화 능력과 적응력을
> 동시에 강화하는 프레임워크를 제안한다.

EN:
> We propose a framework that simultaneously strengthens generalization and
> adaptation in AI by leveraging user trajectory data.
