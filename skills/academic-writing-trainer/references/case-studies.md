## Case 1 — 김윤호: Wasserstein VAE 기반 Skill Encoding (★ 핵심)

**왜 이 케이스를 깊이 다루는가:** 승필의 hwpx 합평 피드백 원문이 보존되어 있어 BEFORE → FEEDBACK → AFTER 3단 비교가 가능한 유일한 사례.

### BEFORE (Week 2 초고)

```
최근 강화학습 분야에서는 다양한 환경, 특히 long-horizon, sparse reward
환경에서 planning을 잘 수행하기 위한 연구들이 많이 진행되고 있습니다.
특히, 시작 상태부터 종결 상태까지 가는 데 필요한 horizon이 너무 길기에
이를 단축시키고자 여러 action과 state들의 sequence인 trajectory를
skill 단위로 묶어서 사용하는 연구들이 진행되고 있습니다. ...

먼저, skill을 추출할 때 state sequence만 사용하는 방식, state와 action
sequence 둘 다 사용하는 방식 등이 있습니다. ...

이를 위해, 이러한 skill을 잘 표현하기 위해 trajectory를 latent space 상의
vector로 표현하는 방식이 주로 사용됩니다. 원본 데이터의 분포를 latent
space에서의 분포로 연결 짓는 대표적인 모델로 베타-VAE가 있습니다. ...

이를 바탕으로, 본 연구에서는 Wasserstein distance를 이용한 VAE를 사용하여
다양한 skill들을 latent로 잘 표현하도록 하고자 합니다. ...

결과적으로 ...
```

### FEEDBACK (승필 hwpx 합평 원문)

```
글의 종류
종류: 새로운 모델의 설명과 그 차별성을 논증하는 제안서

문단 간 전개
- 3, 4 문단의 흐름이 역전됐습니다. 기존 베타 VAE에서 사용하는 KL 발산과
  그 문제점을 먼저 설명하고 이후에 와서스타인 거리와의 비교가 들어올 필요가
  있어보입니다.
- 2, 3 문단을 구분할 필요가 크게 없어 보입니다.
- 5문단은 와서스타인 거리를 채택한 새로운 모델에 대한 설명에 관한 문단입니다.
  하지만, 와서스타인 거리에 전체 글이 초점이 맞춰져 있어, 모델의 구성 요소가
  잘 보이지 않습니다. 해당 문단에서 분석을 통해 설명하거나, 전체 모델의
  차별점을 더 앞서 설명할 필요가 있어 보입니다.
```

**패턴 라벨:**
- R3 흐름 역전 (단락 3, 4)
- R4 인접 단락 분리 불필요 (단락 2, 3)
- R5 초점-내용 불일치 (단락 5에서 모델보다 도구 강조)

### AFTER (Week 4 퇴고본)

```
본 연구는 강화학습에서 기술(skill)을 효과적으로 인코딩할 수 있는
와서스테인 거리 기반 VAE를 제시합니다. 최근 강화학습 분야에서는 다양한 환경,
특히 긴 시간(long-horizon) 동안 보상 없이 행동하고 한 번에 보상을 받는
(sparse reward) 환경에서 ... 이전 연구들에서는 데이터를 압축하는 모델로
주로 β-VAE(Variational AutoEncoder) 인코더가 사용됐지만 β-VAE가 사용하는
KL 발산 정규화 항은 큰 단점을 가집니다. 기존 연구에서 사용됐던 β-VAE와
KL 발산이 갖는 단점에 대해 분석하고 이를 개선하기 위한 와서스테인 거리
(Wasserstein distance)를 접목한 인코더를 소개합니다.

주어진 배열을 기술로 인코딩하는 인코더로는 주로 β-VAE구조의 GRU나 트랜스포머
인코더가 사용됩니다. ... [수식 포함, KL 발산의 메커니즘 설명]

KL 발산의 단점을 보완하기 위해 두 분포의 와서스테인 거리가 사용됩니다.
KL 발산은 정규화과정을 통해 잠재 공간을 한정적으로 사용하도록 강제하기에
데이터의 다양성을 표현하는 것에 한계가 있습니다. ... [Wasserstein distance
도입의 이유 분석]

β-VAE의 KL 발산이 갖는 단점을 보완하기 위해 와서스테인 거리를 접목한 VAE를
이용해서 기술을 잘 압축하는 모델을 제안합니다. 강화학습 분야에서 기술 추출
방식은 ... [차별성 + 모델 구성요소]

결론적으로, 기존의 KL 발산 기반 인코더는 잠재공간을 효율적으로 사용하지
못해서 기술의 의미를 제대로 표현하지 못한다는 단점을 가졌고, 이를 개선하기
위해서 와서스테인 거리를 이용한 VAE를 제안합니다. ...
```

### 변화 분석

| 패턴 | BEFORE | AFTER | 어떻게 고쳤나 |
|---|---|---|---|
| **R3 흐름 역전** | 단락 3에 Wasserstein 도입, 단락 4에 KL 한계 | 단락 2에 KL 메커니즘, 단락 3에 KL 한계 → Wasserstein 도입 | KL 설명/한계가 Wasserstein 앞으로 |
| **R4 단락 분리** | 단락 2·3이 모두 "skill encoding 일반론" | 단락 2가 KL/β-VAE 메커니즘만 다루어 분리 의미 부여 | 한 단락에 한 thesis |
| **R5 초점** | 5단락이 Wasserstein 도구만 강조 | 4단락 차별성을 모델 자체로 끌어옴 | "모델의 구성 요소"를 명시 |

**Coach 변환 (학습용):**

> 이 BEFORE/AFTER가 우리가 본 R3·R4·R5 패턴이 어떻게 고쳐지는지 보여주는 좋은 예시예요. 본인 글에서 비슷한 패턴이 보이면 이 case를 다시 떠올려보세요.

## Case 2 — 김세진: AGI 일반화/적응력 (요약)

**BEFORE 핵심 문제 (추정):**
- 일반화/적응력 정의가 너무 추상적
- 본 연구가 무엇을 하는지 늦게 등장

**AFTER 변화:**
- 첫 단락에 thesis 즉시 lock ("본 연구는 인공지능 모델의 일반화 능력과 적응력을 동시에 강화시켜 ...")
- 모듈 3개 (뉴로-심볼릭 / 프로그램 실행 / 프로그램 평가)로 분석 서술 도입
- 5문단을 7문단으로 확장하여 모듈별 1문단씩 배정

**패턴 라벨:**
- 두괄식 강화 (R5 정렬 강화)
- 분석 서술 도입 (장르 의무 단락 충족)

## Coach가 이 케이스를 활용하는 방법

### 1. 같은 패턴 발견 시 case 인용

사용자가 R3 흐름 역전을 범하면:

> "이건 R3 흐름 역전이에요. 김윤호 case에서 똑같은 패턴이 잡혔었어요. BEFORE에서 단락 3에 새 방법, 단락 4에 기존 한계가 있었는데, AFTER에서는 한계 → 새 방법으로 순서를 바꾸니 훨씬 매끄러워졌어요. 본인 글의 단락 X, Y를 그렇게 바꿔보면 어떨까요?"

### 2. 학습 리포트에서 비교

```
─── 학습 리포트 ───
잡힌 패턴 R3 흐름 역전: 2회 (단락 3, 4)

비교: 김윤호 case도 같은 단락에서 R3가 잡혔어요. AFTER에서 어떻게 고쳤는지
참고하시면 다음 글에서 R3가 줄어들 거예요.
```

### 3. 사용자가 "예시 보여주세요" 요청 시

case 1의 BEFORE/AFTER 표를 그대로 보여주면 됨.
