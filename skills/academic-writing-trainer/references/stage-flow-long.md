# 장문 mode 흐름 — 섹션 Q&A 시작

academic-writing-trainer의 장문 mode (논문·리포트 등 multi-section). Stage 3가 섹션 구조 인터뷰로 시작하고, 그 뒤 단문 흐름이 섹션마다 재귀적으로 펼쳐진다.

---

## Stage 0·0.5·1·2 — 단문 mode와 동일

진단 / 모드·장르·언어 결정 / 의도 1문장 / 내용 1문장. 차이 없음.

차이는 Stage 0.5에서 모드를 "장문"으로 선택한 시점부터 reference가 본 파일로 전환된다는 것뿐.

---

## Stage 3-A — 섹션 구조 Q&A 인터뷰 ★

장문 mode의 핵심 차별 지점.

### 진입 메시지

```
[Stage 3-A] 섹션 구조를 함께 잡아볼게요

장문이라 섹션부터 정해야 해요. 5가지 질문 드릴 텐데, 한 번에 하나씩
답해주시면 돼요.

(언제든 "잘 모르겠어요" 하시면 옵션 제시드려요.)
```

### 5가지 질문 (순서 고정)

#### 질문 1 — 장르·예상 분량

```
Q1. 이 글의 장르와 예상 분량은요?

옵션:
- 학회 논문 8쪽 (CVPR/ICML/NeurIPS short)
- 학회 논문 12쪽 (ACL/EMNLP/KDD)
- 저널 논문 (분량 자유)
- 워크숍 페이퍼 4-6쪽
- 학위논문 챕터
- 기술 리포트 / 백서
- 기타: 직접 입력

예: "ACL 12쪽 long paper"
```

#### 질문 2 — 섹션 개수

```
Q2. 주요 섹션을 몇 개로 잡으실래요?

표준 옵션:
- 5섹션: 서론·관련연구·방법·실험·결론
- 6섹션: 서론·관련연구·문제정의·방법·실험·결론
- 7섹션 이상: 방법이 여러 모듈일 때 (각 모듈을 separate 섹션)

장르별 권장:
- 논문: 5-6
- 워크숍: 4-5
- 리뷰: 5-7
```

#### 질문 3 — 각 섹션 역할

```
Q3. 각 섹션의 역할을 한 줄로 알려주실 수 있어요?

예:
- 1.서론 — 문제 정의 + 본 연구 contribution 4가지 + 글 구조
- 2.관련연구 — 두 축으로 분류 (LLM 기반 / Symbolic 기반)
- 3.방법 — 3-모듈 프레임워크 설명
- 4.실험 — 두 벤치마크 + ablation
- 5.결론 — 한계 + 향후 연구

(어려우시면 Stage 0.5에서 정한 장르 의무 단락에 매핑해드릴게요)
```

#### 질문 4 — 섹션 순서

```
Q4. 섹션 순서는?

대부분 위 그대로지만, 다음 변형도 가능:
- 방법 앞에 "Preliminaries" 섹션 (수학 표기/배경 정리)
- 결론 뒤에 "Limitations" 섹션 분리
- 관련연구를 끝으로 (논문 분야에 따라)
```

#### 질문 5 — 분량 비중

```
Q5. 각 섹션의 분량 비중을 대략 어떻게 잡으실래요?

표준 (12쪽 기준):
- 서론 1쪽
- 관련연구 1쪽
- 방법 4쪽 (가장 큼)
- 실험 4쪽
- 결론 0.5쪽
- (References 1.5쪽)

본인 글의 비중을 알려주세요. 또는 위 표준 그대로 쓰셔도 OK.
```

### Stage 3-A 채점

R1·R2 점검:

| R | 점검 |
|---|---|
| R1 | 장르가 명명되었는가 |
| R2 | 의무 섹션이 모두 포함되었는가 (장르별 minimum) |

장르별 minimum 의무 섹션:

- **논문**: 서론·방법·실험·결론 (관련연구 권장)
- **리뷰**: 정의·축 분류·축별 정리·공통문제·전망
- **리포트**: 요약·배경·방법·결과·결론

R2 미달 시 fail-fast: "이 장르에는 [N] 섹션이 빠지면 안 돼요."

### Stage 3-A 통과

```
✓ Stage 3-A 통과! 섹션 구조 lock 됐어요.

확정된 섹션 구조:
1. 서론 (1쪽) — [역할]
2. 관련연구 (1쪽) — [역할]
3. 방법 (4쪽) — [역할]
4. 실험 (4쪽) — [역할]
5. 결론 (0.5쪽) — [역할]

이제 각 섹션을 단문 mode와 비슷하게 다룰 거예요. 한 섹션마다:
- 섹션의 lead sentences (단락 단위)
- 단락별 prose 작성

어느 섹션부터 시작할까요? (보통 서론부터 권장하지만, 이미 작성 중인
섹션이 있으면 거기부터 가셔도 OK)
```

## Stage 3-B — 섹션마다 lead sentences (재귀)

선택된 섹션 1개에 대해 단문 mode의 Stage 3을 그대로 적용.

### 진입 메시지

```
[Stage 3-B] 섹션 [N]: [섹션 이름] — lead sentences

이 섹션을 [M]개 단락으로 나눌 거예요. 각 단락의 lead 1줄씩.

이 섹션의 역할: "[Stage 3-A에서 정한 역할]"

장르 의무 단락 (이 섹션의 sub-구조):
[해당 섹션의 의무 단락 — 예: 방법 섹션이면 동기·전체구조·구성요소·예시]

각 단락의 lead 1문장씩 적어주세요.
```

R1~R5 점검은 단문 Stage 3와 동일. 단, **섹션 단위**로 적용:
- R2: 섹션 의무 단락 충족
- R3: 섹션 내 단락 흐름
- R4: 섹션 내 단락 중복
- R5: 섹션 lead가 섹션 thesis 지지

### 통과 시

```
✓ 섹션 [N] outline 통과! X/12

다음: 이 섹션의 첫 단락 prose 작성으로 넘어가요. (Stage 4)
```

## Stage 4 — 섹션 × 문단 매트릭스

장문 mode에서 Stage 4는 행렬:
- 행: 섹션 N개
- 열: 섹션마다 단락 M개

### 진행 순서

```
4.1.1  섹션 1 (서론), 단락 1 — 통과까지 반복
4.1.2  섹션 1, 단락 2 — 통과까지
...
4.1.M  섹션 1, 마지막 단락 — 통과까지
   → 섹션 1 통과, 다음 섹션으로
4.2.1  섹션 2 (관련연구), 단락 1
...
```

각 substage는 단문 Stage 4와 동일한 4축 채점 (통과 9/12).

### 섹션 누적 미리보기

매 단락 통과 후:

```
✓ 섹션 [N] 단락 [M] 통과! X/12

지금까지 섹션 [N] 완성 단락:
[단락 1] [단락 2] ... [단락 M ★ 방금]

섹션 흐름 점검: M개 단락이 자연스러운가? 자가 점검 한 번.
다음: 섹션 [N] 단락 [M+1] 작성으로 가시겠어요?
```

섹션 마지막 단락 통과 시:

```
✓ 섹션 [N] ([섹션 이름]) 완성!
평균 점수: X.X / 12

이 섹션의 흐름이 lead로 정한 것과 일치하는지 한 번 자가 점검:
- lead들만 읽어도 섹션 메시지가 명확한가
- 단락 간 인과 정상

다음: 섹션 [N+1] ([다음 섹션])로 넘어가요. Stage 3-B부터 다시 시작.
```

## Stage 5-A — 섹션 단위 통합

각 섹션이 모두 작성된 뒤 섹션 단위 통합 critic.

```
[Stage 5-A] 섹션 [N] 통합 critic (만점 12, 통과 9)

이 섹션의 모든 단락이 통과했어요. 섹션 단위로 한 번 더 점검해요.

점검 항목:
- 단락 간 연결어 정합
- 용어 일관성 (이 섹션 안에서)
- 단락 분량 균형
- 섹션 lead들이 섹션 thesis 지지
```

각 섹션마다 Stage 5-A 1회. 통과 9/12.

---

## Stage 5-B — 전체 문서 통합

모든 섹션 통합 후 전체 문서 통합 critic.

```
[Stage 5-B] 전체 문서 통합 critic (만점 12, 통과 10)

모든 섹션 통과! 이제 전체 문서를 합쳐 다듬어요.

점검 항목:
- 섹션 간 전환 자연스러움
- 용어 일관성 (전체 문서)
- 섹션 분량 비중 (Stage 3-A 결정 vs 실제)
- 서론↔결론 호응
- 약어·표기 통일성
- 인용 cross-reference 일관
- 전체 합산 점수
```

통과 10/12.

## 학습 리포트 (Stage 5-B 통과 후)

단문 mode 학습 리포트와 같은 형식. 추가 항목:

```
─── 학습 리포트 (장문) ───
완성도: 전체 평균 X.X / 12

섹션별 평균:
  서론: X.X
  관련연구: X.X
  방법: X.X
  실험: X.X
  결론: X.X

자주 잡힌 패턴 TOP 5:
[단문보다 패턴이 더 많이 누적될 수 있음]

체화도(섹션별):
  서론(첫 작성): R3 잡힘 N회
  결론(마지막 작성): R3 잡힘 0회 → 체화 진행

분량 비중 (계획 vs 실제):
  서론: 1쪽 / 1.2쪽 (+0.2쪽)
  ...

다음 글에서 의식하면 좋을 것:
1. [권고]

완성된 문서:
[전체 prose, 섹션 단위로 분리]
```

## 장문 mode 사용자 인터럽트 처리

장문은 오래 걸리므로 사용자가 중간에 끊는 경우가 많다.

### 사용자가 "이만 쉴게요" / "내일 이어서"

```
지금까지 완성된 부분 정리해드릴게요:

완성된 섹션: [N개]
진행 중 섹션: [섹션 이름] (단락 [M]까지 통과, 단락 [M+1] 작성 중)

상태를 저장할게요. 다시 시작하실 때 "[섹션 이름] 단락 [M+1]부터 이어서"
하시면 돼요.

수고하셨어요!
```

### 사용자가 특정 섹션만 작성하고 싶을 때

```
"방법 섹션만 작성하고 싶어요" — 가능합니다.

그러면 Stage 3-A는 건너뛰고 (이미 섹션 구조가 머릿속에 있다고 가정),
Stage 3-B부터 방법 섹션의 단락 lead를 정하는 것부터 시작할게요.

방법 섹션의 역할이 무엇인가요? (예: "3-모듈 프레임워크 설명")
```

이 경우 단문 mode와 사실상 같다.
