# 단문 mode 흐름 — 5문단 디폴트

academic-writing-trainer의 단문 mode (5문단 연구 제안서 디폴트)에서 각 단계의 진행 지침. Coach가 매 단계에서 따라야 할 스크립트.

---

## Stage 0 — 진단 (선택, 사용자 요청 시)

```
시작 전에 짧게 글쓰기 자기점검 한번 해볼까요? (10문항)

□ 글을 시작하기가 어렵다
□ 사전 준비 없이 바로 시작한다
□ 무엇에 대해 쓸지 막막하다
□ 몇 줄 쓰면 할 말이 없어진다
□ 생각이 문장으로 표현되지 않는다
□ 서론을 쓰는 것이 어렵다
□ 구성을 짜기가 힘들다
□ 너무 빠르고 쉽게 쓴다
□ 한 편에 너무 많은 시간이 걸린다
□ 다 쓴 뒤 보면 오자/탈자가 많다

체크 6개 이상이면 본 트레이너가 도움이 될 거예요.
```

체크 결과로 사용자 약점 단계 식별. 예: "구성이 어렵다" 다수 → Stage 3에서 더 천천히.

## Stage 0.5 — 모드/장르/언어 결정

```
4가지만 정하고 시작할게요:

1. 모드: 단문(5문단) / 장문(섹션 인터뷰)
2. 장르: 연구 제안서 / 방법론 설명 / 실험 보고 / 리뷰 / 비평 / 기타
3. 언어: KO / EN / KO+EN
4. 통과 임계: 표준 / 엄격 / 관대

(디폴트: 단문 + 연구 제안서 + KO + 표준)
```

장르 결정 후 의무 단락 미리 노출:

```
연구 제안서 5문단으로 가보겠습니다.
의무 단락 5개:

1. 배경 — 무엇이 미해결, 왜 중요
2. 한계 — 기존 방법의 구체적 한계
3. 제안 — 본 연구가 무엇을 제안
4. 차별성 — 기존 대비 다른 점
5. 평가 — 어떻게 검증

이걸 채울 lead sentence를 Stage 3에서 정할 거예요.
지금은 글의 의도부터 정해보겠습니다 (Stage 1).
```

## Stage 1 — 의도 1문장

### 진입 메시지

```
[Stage 1] 의도 한 문장 (만점 9, 통과 7)

이 글이 무엇을 하려는지 1문장으로 적어주세요.

힌트:
- 동사를 명확히 (제안한다 / 보인다 / 분석한다 / 보고한다 중 하나)
- 너무 일반적이지도, 너무 디테일하지도 않게

예: "본 연구는 사용자 궤적 데이터를 활용해 인공지능의 일반화 능력과 적응력을
동시에 강화하는 프레임워크를 제안한다."
```

### 채점 항목 (3축, 각 1-3점)

- **명확성**: 모호 1 / 대체로 분명 2 / 1문장으로 정확히 lock 3
- **적절성**: 장르·독자 미스매치 1 / 장르엔 맞음 2 / 장르·독자·범위 정합 3
- **참신성**: 흔한 재진술 1 / 새 관점 2 / 실질적 새 발상 3

**통과 임계: 7/9 + Insight-first 게이트 통과**

### Insight-first 게이트 (paper-section-rewrite Level 1 Step 1.3과 동일) ★

의도 1문장이 **단순 "what 나열"이면 점수와 무관하게 ✗**. "왜 새로운가 / 무엇을 푸는가"가 보여야 ✓.

```
✗ what 나열:  "본 연구는 모듈 A, B, C를 제안한다."
✓ insight:   "본 연구는 OOD 일반화 격차를 사전 지식 갱신으로 메우는 프레임워크를 제안한다."
```

Coach 처방 예: "지금 의도가 ‘무엇을 만드는지’만 있어요. ‘왜 이게 새로운지 / 어떤 문제를 푸는지’를 한 조각만 넣으면 insight-first가 돼요. 예: ‘…을 제안한다’ → ‘[기존이 못 푸는 X]를 [핵심 발상]으로 푸는 …을 제안한다’."

### Coach 출력 (3단)

```
잘 된 점: [강점]
개선점: [개선점] (원칙: 명확/적절/참신 / Insight-first)
점수: 주제 X/9 (명확 X / 적절 X / 참신 X) | Insight-first: ✓/✗
다음 행동: [통과까지 가장 짧은 길]
```

### Fail 시

```
지금 X/9예요. 통과(7) 까지 한 단계 남았어요. [구체적 처방] 다시 써보실래요?
```

### Pass 시

```
✓ 의도 통과! 7/9
의도가 잡혔어요: "[사용자 thesis]"
다음: 이 의도를 ‘무엇으로’ 달성할지를 1문장으로 정하는 Stage 2로 가요.
```

## Stage 2 — 내용 1문장

### 진입 메시지

```
[Stage 2] 내용 한 문장 (만점 9, 통과 6)

Stage 1의 의도를 ‘무엇으로’ 달성하는지 1문장으로 적어주세요.

Stage 1: "본 연구는 ... 프레임워크를 제안한다."
Stage 2 (예): "구체적으로, 사용자 궤적에서 학습한 가치 예측 모델로 프로그램
합성 모델을 안내함으로써 학습하지 않은 작업까지 해결하는 능력을 보인다."

힌트:
- "X를 Y로 한다" 구조 권장 (X 단독이면 부족)
- 두 가지 claim을 한 문장에 욱여넣지 말기 (Stage 3 분배 깨짐)
- Stage 1과 동사·대상이 모순되지 않게
```

### 채점 항목 (3축)

- **구체성**: "X를 한다" 1 / "Y를 통해 X" 2 / 방법·장치까지 명시 3
- **의도 정합**: 모순 1 / 대체로 정합 2 / 완벽 정합 3
- **단일 claim**: 다중 claim 1 / 한 claim 우세 2 / 단일 claim 명확 3

**통과 임계: 6/9**

### R5 자동 점검

Stage 2 응답에서 글 thesis가 "X 모델 제안"이 아니라 "Y 도구 사용"이면 즉시 경고:

> "잠깐, ‘[Y 도구]’가 thesis 중심이 되는 느낌이에요. Y는 도구이지 모델 자체가 아니에요. 모델 자체의 핵심 발상을 1문장에 넣어주실 수 있을까요? (R5 초점-내용 불일치 패턴이에요)"

### Pass 시

```
✓ 내용 통과! X/9
의도+내용:
  의도: "[Stage 1]"
  내용: "[Stage 2]"

이 두 문장이 글 전체의 thesis예요. 이걸 5개 단락으로 풀어줄 outline을
다음 단계에서 만들어요.
```

## Stage 3 — 5 lead sentences

### 진입 메시지

```
[Stage 3] 5개 단락 lead sentence (만점 12 + R 점검, 통과 9 + R2 통과)

이제 5문단의 outline을 만들 거예요. 각 단락의 첫 문장(lead)만 1줄씩.
(prose는 아직 쓰지 마세요. lead만.)

장르 의무 단락:
1. 배경 — 무엇이 미해결, 왜 중요
2. 한계 — 기존 방법의 구체적 한계
3. 제안 — 본 연구가 무엇을 제안
4. 차별성 — 기존 대비 다른 점
5. 평가 — 어떻게 검증

각 단락의 lead 1문장씩 적어주세요.
```

### R1~R5 + Insight-first lead 자동 점검

채점 전 자동 점검:

| R | 점검 |
|---|---|
| R1 | 사용자가 장르 라벨링 했는가 (Stage 0.5에서 완료) |
| R2 | 5개 lead가 5개 의무 단락에 모두 매핑되는가 (누락 시 fail-fast) |
| R3 | 인접 lead의 인과 순서가 정상인가 (배경→한계→제안→차별성→평가) |
| R4 | 인접 lead가 의미 중복인가 |
| R5 | 모든 lead가 Stage 2 thesis를 지지하는가 |
| **Insight-first lead** | 각 lead가 "what 나열"이 아니라 insight 제시인가 (paper-section-rewrite Level 2 Step 2.5와 동일) |

**Insight-first lead 게이트:** lead가 "본 모델은 ~ 모듈로 구성된다"(what만)이면 ✗. "본 모델은 사전 지식 갱신으로 OOD 격차를 메운다"(why 보임)면 ✓. 위반 lead는 Coach가 재작성 코칭.

### 실험/결과 장르 시 — 의도→방법→결과→해석 흐름 점검 ★

장르가 **실험 보고 / 결과·논의**면 R3 대신(또는 함께) `genre-rubrics.md`의 결과 섹션 내부 흐름을 점검한다.

```
P1 lead [의도/질문]: "본 실험은 ~를 검증한다."
P2 lead [방법 요약]: "ARC 1k에 ~ 모델을 ~ 조건으로 평가한다."
P3 lead [결과]:     "본 모델은 zero-shot 78%로 baseline 대비 +12%p."
P4 lead [해석]:     "이 차이는 사전 지식 갱신 모듈로 설명된다."
```

결과가 의도보다 먼저 나오거나 해석 단락이 없으면 ✗ → Coach가 순서 재배치 코칭.

### Coach 출력 (3단 + R 점검)

```
잘 된 점: [강점, 예: "5개 의무 단락이 모두 채워져 있어요. R2 통과예요."]

개선점:
  단락 X와 Y에서 [구체적 문제]
  → 원칙: R3 흐름 역전 / R4 중복 / R5 thesis 정렬 등

R 점검:
  R1 ✓ R2 ✓ R3 ✗(단락 3,4 역전) R4 ✓ R5 ✓

점수: 구성 X/12 (짜임 X / 간결 X / 핵심 X / 논리 X)

다음 행동: [통과까지 가장 짧은 길]
```

### R2 fail-fast (즉시 NEEDS_WORK)

R2 위반 시:

```
잠깐, 의무 단락 [N]번 ‘[역할]’이 비어 있어요.
이 글의 장르는 [장르]이고, 이 단락이 빠지면 독자가 길을 잃어요.
(이게 우리가 본 R2 ‘의무 단락 누락’ 패턴이에요. 승필 합평에서 자주 나왔어요.)

[단락 N] lead를 추가해주실 수 있을까요?
```

### Pass 시

```
✓ outline 통과! X/12 + R 모두 통과

지금 잡힌 5문단 lead:
1. (배경) [lead 1]
2. (한계) [lead 2]
3. (제안) [lead 3]
4. (차별성) [lead 4]
5. (평가) [lead 5]

이걸 prose로 풀어쓸 거예요. 한 문단씩, 통과 점수까지 다듬으면서.
첫 단락(배경)부터 시작할게요. 준비되셨어요?
```

## Stage 4 — 문단별 substage

### 4.1 ~ 4.5 공통 진입

```
[Stage 4.{N}] 단락 N — [역할] 작성 (만점 12, 통과 9)

이 단락의 lead:
> "[lead N]"

이 단락의 역할별 권장 흐름:
   [예: 한계 단락 = 비교/대조 → 분석 → 인과]
의무 카테고리: [예: 분석, 인과]
회피: [예: 정의 일변도]

지금까지 완성된 단락:
  단락 1: [완성본]
  ...
  단락 N-1: [완성본]

위 lead를 풀어서 단락 N의 prose를 써주세요. 권장 분량 3-5문장.

원칙 미리 보기:
- 두괄식: lead가 첫 문장
- 통일성: 한 단락 한 주제
- 연결성: 인접 문장의 순리적 배열
- 완결성: lead의 충분한 뒷받침
- 9가지 서술 방식: 정의/분류/분석/비교/예시/인용/유추/과정/인과 (writing-principles-ko.md)
- 금지어: 것이다 / 수 있다 / 에 대한 / 됩니다 등 의식
```

### 채점 (4축 통합, 12점) + Level-4 게이트 배터리 (paper-section-rewrite v4와 동일)

**4축 (각 1-3점, 통과 9/12):**
- **통일성** (1-3): lead와 문장들이 한 주제로 수렴
- **연결성** (1-3): 문장 간 순리적 배열
- **완결성** (1-3): lead가 충분히 뒷받침
- **표현** (1-3): 금지어·문법·주술 명확

**4축과 별개로 아래 게이트는 하나라도 위반 시 substage ✗ (점수 무관 재작성):**

| 게이트 | 통과 조건 | 위반 시 Coach 처방 |
|---|---|---|
| **한 문장 한 역할** | 모든 문장 단일 카테고리 (하이브리드 `[정의(+인과)]` 금지) | 두 카테고리 문장을 두 문장으로 분할 |
| **단문 비율 ≥ 60%** | 단락 안 KO 50자 / EN 20w 이내 문장 비율 ≥ 60% | 긴 문장 분할·압축 ("이 단락 단문 40%예요. 두 문장만 쪼개면 67%로 통과예요") |
| **자연스러움** | 계사 대용(§7 "해당한다/위치한다/기능한다/자리매김/방향에 있다") + 동족어 stacking(§8 "산출물을 산출/연구의 연구") + register 불일치(§9 "아니한다↔끌려간") + 번역투 + em-dash 누적 < 3 | 단정문·쉬운 동사로 ("‘맥락에 위치한다’ → ‘이 흐름과 연결된다’") |
| **논리적 비약 0** | 인접 문장 추론 단계 명시 (수치→결론에 baseline·유의성 빠짐 ✗) | 중간 추론 한 문장 추가 또는 한정 표현 |
| **ML-beginner** | 약어 first-use 풀어쓰기 / 수식 전 자연어 / 한 문장 jargon ≤ 3 / **서술형 풀어쓰기(명사형 종결 금지)** | "명사형으로 굳히지 말고 ‘~을 ~한다’로 풀어쓰기" |

**서술형 풀어쓰기 (가장 자주 잡는 안티패턴):**
```
✗ "본 방법은 메타인지 표현의 효과적 활용을 통한 일반화 향상이다."
✓ "본 방법은 메타인지 표현을 학습 신호로 쓴다. 이 신호는 분포 밖 입력에서도 일반화를 끌어올린다."
```

### 정량 grep 자동 실행

매 round Coach가 prose에 grep 적용 (banned-phrases-ko.md):

```
정량 grep:
  것이다 / 수 있다: N개         (≥3 → 표현 -1)
  에 대한 / 에 의해 / 을 통해: N개  (≥3 → -1)
  명사형 (-적인/-적으로): N개      (≥3 → -1)
  계사 대용 (해당한다/위치한다/기능한다/자리매김, §7): N개  (단락 0 권장)
  동족어 stacking (산출물을 산출 등, §8): N개  (문장당 0)
  하고자 한다 / 할 것이다: 평서종결 대비 비율  (≤ 0.3 목표, >0.5 ✗)
  register 이탈 (아니한다/상기 ↔ 끌려간/흔들림, §9): N개  (합산 <2)
  됩니다 / 되어진다 (피동): N개   (0 권장)
  em-dash (—): N개               (0 강제)
  단문 비율: N%                  (≥60% Hard)

임계 초과: [임계 넘은 항목]
```

### Coach 출력 (★ 문장 단위 카테고리 라벨 + 3단 + 점수 추이)

```
=== 단락 N ([역할]) 시도 K ===

이 단락의 권장 흐름: [정의 → 분석 → 과정] (writing-principles-ko.md)
의무 카테고리: [정의, 분석]

문장별 서술 방식 라벨:
S1 [정의]   "[사용자 문장 1]"   ✓ lead로 적절
S2 [분석]   "[사용자 문장 2]"   ✓ 정의 → 분석 자연스러움
S3 [예시]   "[사용자 문장 3]"   ⚠ 권장 흐름엔 없음 — 검토
S4 [인과]   "[사용자 문장 4]"   ⚠ 인과는 차별성 단락 영역

흐름: 정의 → 분석 → 예시 → 인과
역할 정합도: 3/5 — 의무 [정의, 분석] 충족, 권장 [과정] 누락

[정량 grep]
```

## Stage 5 — 통합

### 진입 메시지

```
[Stage 5] 5문단 통합 (만점 12, 통과 10)

5개 단락이 모두 통과했어요. 이제 합쳐서 한 번 더 점검해요.

전체 점검 항목:
- 단락 간 연결어 정합 (그러나/따라서 등이 인접 단락 인과와 맞는가)
- 용어 일관성 (같은 개념을 다르게 부르지 않는가)
- 분량 균형 (한 단락이 다른 단락의 2배 이상이면 경고)
- 첫 단락 ↔ 마지막 단락 정렬 (도입 thesis와 결론 contribution 호응)
- "~하고자 한다" 비율 (글 전체) ≤ 0.3 — 계획·절차는 단정형, 목표·기여만 한정적
- 개념어 과반복 회전 — 글쓴이가 만든 비표준 합성어가 글 전체 ≥ 5회면 회전 (표준 학술 용어는 반복 OK)
- 전체 합산 점수
```

### 채점 (12점)

- **전환** (1-3): 단락 간 접속어·전환 자연스러움
- **일관성** (1-3): 용어·약어·표기 일관
- **균형** (1-3): 단락 분량·디테일 균형
- **호응** (1-3): 도입↔결론 호응

**통과 임계: 10/12 + "~하고자 한다" 비율 ≤ 0.3 + 개념어 과반복(비표준) < 5**

비율·과반복 위반 시 Coach 처방: "이 글에 ‘~하고자 한다’가 8번이에요. 계획·절차 문장은 ‘진행한다 / 수행한다’로 단정하고, 연구 목표 한 문장만 ‘기여하고자 한다’로 남기면 글에 힘이 생겨요. 그리고 ‘단일한 분석 틀’이 6번 반복돼요 — ‘같은 분석 틀 / 공통 기준 / 동일한 코딩 체계’로 분산해볼까요?"

### Coach 출력

```

점수: 통합 X/12 (전환 / 일관 / 균형 / 호응)

전체 평균: 단락별 평균 X.X + Stage 5 X = 종합 X.X / 12

다음 행동: [통과까지 1가지]
```
