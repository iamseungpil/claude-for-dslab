# 기록 3층과 `CLAIMS.md` 스펙

## 왜 3층인가

기록이 한 층이면 **원자료 정정이 헌법 개정이 된다.** 실측: 어떤 프로젝트의 헌법 1,480행에
정정·철회 마커가 **61건**(24행마다 하나) 쌓였다. 원인은 수치와 판정을 헌법에 직접 썼기 때문이다.

| 층 | 파일 | 성격 | 규칙 |
|---|---|---|---|
| **L1 원장** | `records/ledger.tsv` | 원자료. 기계 판독. | **절대 수정 금지**(append-only) |
| **L2 주장** | `records/CLAIMS.md` | **현재 상태** | **덮어쓴다**. 이력은 L1에 있다 |
| **L3 헌법** | `CONSTITUTION.md` | L2에서 승격된 것만 | **수를 쓰지 않는다. 문장만.** |

> **헌법에 수를 쓰지 않으면 정정이 헌법에 안 쌓인다.**
> 수는 L1, 상태는 L2, 원칙은 L3.

## `CLAIMS.md` 항목 스펙

```markdown
### C-017 · 잠재-MDL(posterior ELBO)은 CE에 무기여
- 상태:   기각(크리스탈) · **미검정(ARC)**
- 범위:   크리스탈 2×2 셋업. ⚠ARC 외삽 금지
- 근거:   d_KL −0.0270 · 타깃부호 0/5 · `INSIGHTS.md` 사전등록 X (0724)
- 닫는 것: 크리스탈에서 잠재-MDL 주효과 재시도 · MDL 재프레이밍
- 여는 것: ARC에서 `y_feat` 배선 후 1회 측정 (미검정이므로)
- 재확인:  1
```

### 필드 규칙

**상태** — `지지` / `기각` / `미검정` / `조건부`. **도메인마다 따로 적는다.**
한 도메인의 기각을 다른 도메인으로 외삽하는 것이 재확인의 최대 원인이다.

**범위** — 모집단·조건·셋업. *"⚠외삽 금지"* 를 명시적으로 쓴다.

**근거** — `파일:행` 또는 `파일 §절`. **수치와 함께.** 근거를 못 대면 항목을 만들지 않는다.
(대장에 근거 없는 칸을 매 점검 복사한 결과, 한 성분을 **열 번 넘게** 오보한 사례가 있다.)

**닫는 것** — ★이 필드가 없어서 닫힌 문을 두드린다.
판정문은 *"무슨 일이 있었나"* 를 적고 *"이제 무엇이 무의미한가"* 를 안 적는다.
`게이트 0.0007 vs 밴드 0.10 ⇒ 사다리 정지` 는 서사다.
`⇒ 이 사다리 위 실험 X·Y·Z 는 무의미` 가 규범이다.

**여는 것** — 부정 결과가 지정하는 다음 수. **부정 판정을 막다른 길로 남기지 않는다.**
`기각(크리스탈)` 은 `미검정(ARC)` 을 연다. 그걸 안 적으면 "다 닫혔다"로 읽힌다.

**재확인** — 같은 결론을 다시 산 횟수. **정수.**
**2 이상이면 색인을 고치는 게 아니라 게이트를 고친다** (SKILL §7).

## 운영 규약

### 실험 설계 전
```
grep -n "<개념어>" records/CLAIMS.md
```
**어느 주장을 여는지 못 대면 발사하지 않는다** (G1).
실측 근거: 놓친 개념 6개를 수치 대장에서 grep 하면 **1/6** 만 찾히고,
개념 색인에서는 **6/6** 이 찾힌다. **대장은 수를 색인하지 개념을 색인하지 않는다.**

### 실험 후
1. 주장을 **추가**하거나 **상태를 바꾼다**.
2. **L2 갱신 없이 판정문을 쓰지 않는다.**
3. 판정 난 사전등록은 `archive/` 로 옮긴다 — 안 그러면 전부 현재형으로 보인다.

### 압축
**주장 20개마다 리뷰 1회.** 중복 병합, 승격 후보(L3) 표시, 죽은 항목 archive.
과학은 논문 → 리뷰 → 교과서로 압축한다. **압축 계층이 없으면 논문만 620개가 쌓인다.**

## 안티패턴

| 하지 말 것 | 왜 |
|---|---|
| 주장 대장에 ⛔정정 블록을 append | *"지금 무엇이 참인가"* 를 읽을 수 없게 된다. 68행 대장조차 자기모순이 났다 |
| 근거 없는 칸을 복사 | 오보의 직접 원인. **`미확인` 이라 쓴다** |
| 도메인 표기 없이 `기각` | 다른 도메인에서 "이미 닫혔다"로 잘못 읽힌다 |
| 판정문만 쓰고 L2 생략 | 다음 사람(=다음 주의 나)이 못 찾는다 |
