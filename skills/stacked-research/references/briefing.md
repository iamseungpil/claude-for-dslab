# 사람에게 보고하는 법

**보고의 길이는 진행량이 아니라 *결정 유무*가 정한다.**
진행 상황 나열은 보고가 아니다 — 사람이 읽고 **아무것도 안 바뀌면** 그건 소음이다.

`paper-digest` 의 **통찰 우선**(Context → Insight → Evidence → Implication) 구조를 상태보고로 옮긴다.
차이 하나: 논문 요약은 *"왜 중요한가"* 로 끝나지만, 상태보고는 ***"당신이 지금 결정할 것"*** 으로 끝난다.

---

## 유형 A · 틱 보고 — 결정이 없을 때 (**5줄 이내**)

루프가 도는 중이고 사람이 지금 할 일이 없을 때. **짧을수록 좋다.**

```
지금: <한 줄. 무엇이 돌고 있나 / 무엇을 기다리나>
바뀐 것: <지난 보고 대비 델타. 없으면 "없음">
다음: <자율로 진행할 것>
결정 필요: 없음
```

**규칙**
- **델타만 적는다.** 지난 보고에서 안 바뀐 것을 다시 인쇄하지 않는다.
- **"승인 대기 목록"을 매 틱 재인쇄하지 않는다.** 그건 보고가 아니라 반복이다.
- ⛔**할 일이 없으면 그렇게 답하고 멈춘다.** 자동 프롬프트(cron·loop)라도 마찬가지다.
  *"바뀐 것 없음 · 결정 대기"* 가 정직한 답이면 5줄로 끝낸다.

---

## 유형 B · 결정 보고 — 사람이 골라야 할 때

**여기만 길어도 된다.** 그러나 구조는 고정이다.

```
### 결정: <한 줄 질문>

**상황** — 무엇이 이 결정을 만들었나 (2~3줄, 수치 포함)
**핵심** — 왜 이게 갈림길인가. ★사람이 모를 수 있는 통찰 하나
**선택지**
  (가) ... — 비용 ..., 얻는 것 ..., 잃는 것 ...
  (나) ... — 〃
**권고** — 하나를 고르고 이유. "알아서 하세요" 금지
**되돌릴 수 있나** — 예/아니오. 아니면 무엇이 되돌릴 수 없나
```

**규칙**
- **권고를 반드시 낸다.** 선택지만 나열하는 것은 결정을 미루는 것이다.
- **비용을 수로 적는다.** "오래 걸림" 대신 "GPU 6시간".
- **되돌릴 수 있는 결정은 크게 취급하지 않는다.** 되돌릴 수 없는 것만 무겁게 묻는다.
- 선택지는 **2~3개.** 4개가 넘으면 아직 정리가 안 된 것이다.

---

## 유형 C · 판정 보고 — 실험이 끝났을 때

`paper-digest` 구조를 그대로 쓴다. **통찰이 먼저, 수치는 근거로.**

```
### <한 줄 결론 — 수치가 아니라 문장으로>

**맥락** — 무엇을 물었나
**통찰** — ★무엇을 알게 됐나. 다른 해석이 왜 틀리나
**증거** — 표 하나. 반드시 **기준선을 같은 칸에**
**함의** — 무엇이 닫히고 무엇이 열리나 (= CLAIMS 의 닫는 것/여는 것)
**결정 필요** — 있으면 유형 B로, 없으면 "없음"
```

**규칙**
- **결론을 수치로 시작하지 않는다.** `Δ +0.0181 [+0.0115,+0.0249]` 이 아니라
  *"더 학습하면 적합만 오르고 전이는 안 온다"* 로 시작한다.
- **모든 수 옆에 기준선.** 기준선을 못 대는 수는 헤드라인에 쓰지 않는다.
- **⛔금지 문장 목록을 함께 낸다.** 이 결과로 **말할 수 없는 것**을 명시한다.
  (과장은 보고 시점이 아니라 **인용 시점**에 생긴다.)

---

## 세 유형 공통

### 항상 붙이는 것
- **근거는 `파일:행`** 으로. 기억으로 인용하지 않는다.
- **표본 수를 적는다.** 일반 진술 앞에 `n=`.
- **미확인은 미확인이라 쓴다.** 근거 없는 칸을 복사하지 않는다.

### ⛔쓰지 않는 표현

| 금지 | 대신 |
|---|---|
| *"잘 진행되고 있습니다"* | 무엇이 바뀌었는지 델타로 |
| *"거의 다 됐습니다"* | 남은 것을 항목으로 |
| *"~인 것 같습니다"* (측정 가능한 것에) | 재고 나서 말한다. 못 쟀으면 *"미측정"* |
| *"유의미한 개선"* | 수치 + 기준선 + CI |
| *"여러 실험을 진행했습니다"* | 몇 개, 무엇이 바뀌었나 |
| 진행 상황 나열 | **결정에 영향을 주는 것만** |

### 판별 질문 — 보고를 쓰기 전에

> ***"이 보고가 사람의 다음 행동을 바꾸는가?"***

안 바꾸면 **유형 A로 5줄**이다. 길게 쓰고 싶은 충동은 대개
*"열심히 했다는 걸 보여주고 싶다"* 이고, 그건 보고의 목적이 아니다.

---

## 주기

| 언제 | 유형 |
|---|---|
| 루프 틱 · 잡 대기 중 | **A** (5줄) |
| 갈림길 도달 · 승인 필요 | **B** |
| 실험 완주 · 판정 확정 | **C** |
| 방향이 바뀌었을 때 | **C + B** |

**A를 세 번 연속 보냈고 델타가 계속 "없음"이면 — 루프를 멈추고 B로 물어라.**
할 일이 없는데 도는 루프는 대체활동을 만든다.
