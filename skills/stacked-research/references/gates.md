## G1 · CLAIMS grep — 이 실험이 어느 주장을 여는가

```bash
grep -n "<개념어>" records/CLAIMS.md            # 개념으로
grep -n "닫는 것" records/CLAIMS.md | grep "<주제>"   # 닫힌 문 확인
```

**출력에 답할 것**: 이 실험이 여는 주장 ID, 그 주장의 현재 상태, 왜 지금 여는가.
**못 대면 발사하지 않는다.**

⚠**사전 고정된 게이트를 먼저 찾아라.** 과거 판정문이 *"X가 (b) 이상일 때만 진행"* 처럼
**미래 경로를 미리 닫아 놓은** 경우가 있다. 그걸 모르면 닫힌 문을 두드린다.

## G2 · 발화 검사 — 선언한 성분이 실제로 도는가

**두 프로젝트에서 독립으로 9건이 "코드에 있는데 0회 발화"였다.** 가장 값싸고 가장 강한 검사다.

### 학습 성분: 손실 그래프에서 뽑는다

```python
# 트레이너 시작 시 1회. 값은 선언이 아니라 그래프에서.
intent = {
  "H_mdl":        "on" if (kl is not None and kl.grad_fn is not None) else "off",
  "H_ruler":      ruler_name if uses_ruler_loss else "none",
  "H_equiv":      f"on(λ={lam})" if lam > 0 else "off",
  "noaug":        not uses_augmentation,
  "conditioning": cond_name,
}
json.dump(intent, open(f"{outdir}/INTENT.json", "w"), ensure_ascii=False, indent=1)
print("[intent]", intent, flush=True)
```

**규칙**: 사전등록이 켰다고 선언한 성분이 `INTENT.json` 에서 `off` 면 **발사 취소.**
선언은 문서에 있고 배선은 코드에 있다. **둘이 갈라져도 아무도 안 잡는 것이 기본값이다.**

### 실행 경로: 계약당 테스트 하나

```python
def test_wiring_<계약>():
    """기록된 런에서 이 경로가 최소 한 번 발화했는가."""
    assert count_calls(log, "<함수/절>") > 0
```

단위 테스트는 *"함수가 옳게 도는가"* 를 보지 *"라이브 경로에서 호출되는가"* 를 안 본다.
그래서 배선 실패를 전부 통과시킨다.

### ★게이트 자신의 커버리지를 재라 — **fail-open 게이트는 가짜 초록이다**

게이트가 검사 대상을 **하드코딩 경로**로 열거하면, **모르는 트리는 조용히 통과**한다.

```python
ACTIVE = ("experiments/arc", "experiments/sudoku/order_mdl", ...)  # ← 새 디렉터리는 안 보인다
```

**실측 사고**: 잠긴 정본을 피해 새 디렉터리에 사본을 만들었더니 — 그 사본이
**헌법이 금지한 손실**(`FORBIDDEN_LOSS`)을 담은 채 **게이트 시야 밖**에 있었다.
게이트는 `FAIL 0` 을 찍었고, 그 코드로 낸 재현 수를 "챔피언 검증"으로 보고했다.
정본화 계획서가 그 계보를 **"폐기됨"** 이라고 이미 명시해 뒀는데도 6일간 아무도 못 봤다.

**규칙 셋:**
1. **게이트는 검사한 파일 수를 출력한다.** 그 수가 줄면 **FAIL** 이다(회귀, G5).
2. **모르는 트리는 fail-closed.** 저장소의 모든 `.py` 를 세고, ACTIVE ∪ QUARANTINE 에
   안 잡히는 것이 있으면 **분류를 요구**한다. 침묵 통과 금지.
3. **잠금은 확장 지점을 함께 준다.** 파일 하나만 sha 고정하고 확장 통로를 안 주면
   **잠금을 피해 포크가 생기고, 그 포크는 게이트 밖에서 자란다.**

### 죽은 표면은 남기지 않는다
도달 불가 호출부·소비처 없는 텔레메트리는 **배선하거나 지운다.**
어중간하게 살아 보이는 죽은 코드가 **오진의 직접 원인**이었다.

## G3 · 해상도 — 주 지표가 움직일 수 있는가

### G3-0 · 먼저: 지표를 **가설에서 유도한다**

⚠**게이트를 통과 못 하는 가장 흔한 이유는 규율 위반이 아니라 잴 수 없는 지표를 골라 온 것이다.**
실측: 주 지표 `pass1` 이 `0/419` 로 고정된 채 **11일**을 돌았다. 사전등록 76건이 전부
"게이트 통과"였는데 아무것도 구별하지 못했다.

**절차 다섯 — 각 단계를 명령으로 확인한다.**

**① 가설을 구별 진술로 바꾼다.**
```
✗ "모델이 규칙을 배웠다"            ← 못 잰다
✓ "규칙을 배운 모델과 표를 외운 모델이 <조작> 에서 갈린다"
```
*무엇에서 갈리는지 못 적으면 그 가설은 아직 반증 가능하지 않다.* 지표를 찾기 전에 여기로 돌아가라.

**② 갈리는 조작을 찾는다.** 두 가설이 **반대 예측**을 하는 개입:

| 조작 | 언제 | 두 예측 |
|---|---|---|
| **불변성 변환** | 가설이 *"구조를 배웠다"* 일 때 | 규칙 읽는 모델 = 불변 · 외운 모델 = 붕괴 |
| **정보 차단** | 가설이 *"채널 X를 쓴다"* 일 때 | X 제거 시 붕괴 vs 무변화 |
| **절제** | 가설이 *"성분 Y가 기여한다"* 일 때 | Y 제거 시 하락 vs 무변화 |
| **오라클 주입** | 가설이 *"Z가 병목이다"* 일 때 | Z를 공짜로 주면 해결 vs 안 됨 |

**③ 바닥을 만든다 — 추정하지 말고 실제로 돌린다.**
```python
# 그 능력이 정확히 0일 때의 값. 같은 모집단·같은 채점기로.
floor_copy    = evaluate(lambda x: x)                    # 아무것도 안 하기
floor_destroy = evaluate(model, op=rule_destroying_op)   # 규칙을 부수는 조작
```
⛔**다른 실험에서 기준선을 끌어오지 마라.** 실측: 그 착오로 판정문 하나가 통째로 뒤집혔다.
**같은 실행 안에서 계산한다.**

**④ 천장을 만든다.** 자명한 규칙 · 오라클 · 손으로 짠 한 줄.
*천장이 낮으면(자명한 규칙이 이미 잘하면) 그 지표로는 학습을 정당화할 수 없다.*

**⑤ ★조작 자체를 배선검사한다.**
```python
# 구조적으로 답이 정해진 대조군에 같은 조작을 건다.
# 예: 등변인 게 자명한 한 줄 규칙 → 불변성 조작 하에 값이 안 변해야 한다
assert abs(evaluate(trivial_rule, op=T) - evaluate(trivial_rule)) < tol
```
**안 나오면 무너진 것은 모델이 아니라 조작이다.** 이 검사 없이 낸 진단은 믿을 수 없다.

### G3-0b · 판별 질문 셋 — 하나라도 걸리면 주 지표로 쓰지 않는다

| 질문 | 걸리면 | 실측 |
|---|---|---|
| ***"암기로 이 수를 올릴 수 있나?"*** | **가설 지표가 아니다** | `pass1_trained` 가 암기로 **1.0000** 이 됐고 같은 모델의 규칙 성분은 **0.0029**(바닥 0.0033) |
| *"바닥·천장 간격 > 잡음바닥인가?"* | 좁으면 **읽을 수 없다** | 잡음바닥 0.0016 인데 팔 차이 0.0056 — 쌍 단위 62% 불일치 |
| *"최종지표와 **인과**로 연결되나?"* | 상관뿐이면 **대리 지표** | 두 수가 0.41 로 붙어 있었지만 최종지표와 **자릿수 22개** 차이 |

### G3-0c · 실례 — 이 절차로 만든 지표

```
가설    "모델이 규칙을 배웠다"
① 구별  규칙을 읽으면 색 이름이 바뀌어도 같은 답 · 표를 외웠으면 무너진다
② 조작  시연·질의·정답에 **같은** 색 치환 σ  (규칙은 글자 그대로 보존)
③ 바닥  규칙파괴 치환 0.0033 · 무학습 복사 0.0061
④ 천장  시연 최빈색 한 줄 규칙 0.5210
⑤ 배선  그 한 줄 규칙에 σ 적용 → 0.5274 → 0.5210 ✅불변 (조작이 문제를 보존한다)
────────────────────────────────────────────────────────────
결과    0.0029  ← 바닥과 같은 자리. 등변 성분 = 0
```
**`pass1` 로는 영원히 안 보였을 것이 한 번에 보였다.** 그리고 이 지표는
**암기로 못 올린다** — 치환이 암기를 지운다. 그래서 가설 지표다.

### G3-0d · 지표 개수

**가설마다 하나. 프로그램 전체에 고정.**
실측: 사전등록 76건이 주 지표를 **거의 76개** 만들었고(`acc_r1`·`p_copy`·`cover_a1`·`d_null`…
대부분 1회 등장), 그래서 **결과가 위로 안 쌓이고 옆으로 늘어섰다.**
76건을 다 읽어도 *"지난주보다 나아졌나"* 에 답할 수 없다.

⇒ **새 주 지표 도입은 승인 사항**(SKILL §9). 지표 고정이 사전등록 폭발의 상류 처방이다.

### G3-1 · 그다음: 세 수를 발사 전에 댄다

| | 무엇 | 못 대면 |
|---|---|---|
| **바닥** | 아무것도 안 하는 팔의 값 (복사·상수·무학습) | 개선인지 아닌지 모른다 |
| **천장** | 자명한 규칙·오라클의 값 | 목표가 어디인지 모른다 |
| **잡음바닥** | **A-vs-A**: 같은 설정 다른 시드 두 런의 차이 | 팔 차이를 읽을 수 없다 |

```python
# A-vs-A 잡음바닥 — 팔을 비교하기 전에 반드시
delta_AA = metric(run_seed1) - metric(run_seed2)   # 같은 설정!
# 팔 차이가 |delta_AA| CI 안에 들어가면 그 비교는 읽을 수 없다
```

**실측 경고**: 어떤 실험에서 A-vs-A 잡음바닥이 0.0016 이었는데 팔 차이가 0.0056 이었다.
**쌍 단위로는 62%가 불일치**했다 — 거시 집계만 신뢰할 수 있었다.

⚠**주 지표가 0/N 으로 고정돼 있으면(해상도 0) 무엇을 해도 0 이다.**
그런 지표를 들고 있으면 실험이 서로 구별되지 않는다. **해상도 있는 지표를 먼저 만들어라.**

⚠**조건부 지표**(어려운 부분을 공짜로 주고 나머지만 채점)를 주 지표로 쓰면
**그 조건 밖의 파괴 비용을 구조적으로 못 본다.** 실측: 주 지표가 +0.018 오르는 동안
end-to-end 순효과가 **+1.04 → −0.56 으로 부호가 뒤집혔다.**
⇒ 조건부 지표를 쓰면 **그 조건 밖을 같은 사전등록 안에서 함께 잰다.**

## G4 · 통제군 — **이 주장에 대한 *최강* 기존 방법**

> ★**2026-08-03 개정 (§7 트리거, 재확인 5회째).** 이전 문구는 *"학습 0인 고전 팔이 있는가"* 였다.
> **그것으로는 부족하다.** 통제군이 **있었는데도** 헤드라인이 다섯 번째로 뒤집혔다 —
> **약한 통제군**이었기 때문이다.

### G4-0 · 먼저: **주장을 특정하고, 그 주장의 최강 상대를 적어라**

```
주장:        <한 문장>
최강 상대:   <이 주장에 대해 현재 가장 좋은 기존 방법>   ← 이 칸이 비면 발사 금지
그 성적:     <수치 + 출처 파일:행>
```

**실측 사고**: 같은 결과 0.243 을 기준선만 바꿔 읽으면 —

| 기준선 | 순증분 | 읽힘 |
|---|---|---|
| naked-single 0.028 | **+0.215** | "대성공" |
| naked+hidden 0.118 | **+0.125** | "성공" |
| **α_∞ 0.370** | **−0.127** | 음성 |
| **완전 탐색 1.000** | **−0.757** | 완패 |

**넷 다 같은 실험이다. 기준선이 결론을 정했다.** 그리고 `α_∞ 0.3700` 은 **기록에 이미 있었다**
(`INSIGHTS.md:1922`) — 안 찾아서 약한 쪽과 비교했다.

### G4-0b · ★**주장의 범주와 통제군의 범주가 같아야 한다**

같은 날 반대 방향 실수도 났다 — *"재귀 생성기가 관측에서 규칙을 배우나"* 라는 주장에
**규칙이 사람에게 주어진 고전 탐색기**를 대조군으로 놓았다. **범주 오류다.**

| 주장 | 정당한 최강 상대 | ⛔부당한 상대 |
|---|---|---|
| *"우리가 이 문제를 푼다"* | **모든 방법 중 최강** (탐색 포함) | 약한 고전 팔 |
| *"우리가 더 데이터 효율적으로 **배운다**"* | **다른 학습·생성 방법** | **규칙이 주어진 알고리즘** |
| *"성분 X 가 기여한다"* | **X 만 뺀 같은 시스템** | 다른 시스템 |

**두 질문에는 두 통제군이 필요하다.** 하나로 둘을 판정하면 한쪽은 반드시 틀린다.
⇒ **주장을 먼저 문장으로 쓰고, 그 문장의 범주에 맞는 최강 상대를 고른다.**

### G4-1 · 그다음: 학습 0인 팔이 있는가

**역사상 수익률 1위이자 결측률 1위.** 한 프로젝트에서 사전등록 76건 중 **29건(38%)** 이
통제군을 안 적었고, 헤드라인이 **세 번** 이 항목 때문에 뒤집혔다.

| 상황 | 반드시 붙일 통제군 |
|---|---|
| 학습된 게이트/선택기 | **그 특징에 내장된 고전 알고리즘 자체** |
| 생성·복원 | **아무것도 안 하기**(입력 그대로 복사) |
| 자·랭커 | **무작위 자**(rand_distill) |
| 반복·정제 | **같은 예산의 무개입 팔** |
| 조건화 | **조건 제거 팔**(정보를 뺀 바닥) |

**통제군 정합의 네 축** — 넷을 다 맞춰야 비교가 된다:
① 정보 ② 결정론성 ③ 상태 적응성 ④ **개입 예산(실제로 바뀐 것의 수)**

⚠**절대 비율을 고전 대조군 없이 보고하지 않는다.** `0.022 달성` 이 고전 전파 `0.118` 에
눌리고, 심지어 **진부분집합**이었던 사례가 있다.

⚠**상대 delta 가 올랐다고 좋아진 게 아니다.** 분모(통제군)가 더 내려간 것일 수 있다.
**상대가 오르면 절대의 부호를 반드시 확인한다.**

## G5 · 회귀 벤치 — 이 변경이 이미 되던 것을 깨뜨렸나

**G1~G4는 전부 "이 실험을 읽을 수 있는가" 게이트다. "내가 무엇을 깨뜨렸나"는 아무도 안 본다.**

### 왜 이 게이트가 생겼나 — G1~G4를 통과한 변경이 실패했다

실측: 프롬프트 한 문장이 주장도 있고(G1), 발화했고(G2), 주 지표를 3배 올렸고(G3),
테스트 918개가 초록이었는데 — **다른 능력을 4주간 0으로 만들었다.**
발견까지 열흘, 원인 국소화는 커밋 이등분으로만 됐다.

### 왜 단위 테스트가 못 잡나

테스트는 **함수의 계약**을 보고, 회귀는 **시스템의 능력**에서 난다.

### 벤치 고르는 법 — **그 실패를 볼 수 있는 것만 벤치다**

⚠ 가장 흔한 오류: 그럴듯한 재생 스크립트를 게이트로 쓰는 것.
**기록된 행동을 그대로 재발행하는 재생은 의사결정이 없어서 정책 변경에 무감각하다.**
그런 것은 *환경 무죄 확인*이지 회귀 게이트가 아니다.

```
벤치 후보를 고르기 전에 답할 것:
  "과거의 그 회귀를 이 벤치가 잡았을 것인가?"
  못 잡으면 벤치가 아니다. 실제로 그 회귀를 잡은 측정이 무엇이었는지 찾아라.
```

실측: 회귀를 실제로 국소화한 것은 **한 구간 10라운드에서의 행동 입도**였다
(게이트 ON 116라운드 중 115개가 최소값에 고착 · OFF 10라운드 중 5개가 정상).
LLM 호출이 드는 대신, 승인 한 번의 지연보다 쌌다.

### 하네스 점수표 — 이등분을 없애는 물건

```
# harness_score.tsv — 정본이 바뀔 때마다 한 줄
H     commit    date      <지표1>  <지표2>  <지표3>   비고
H-07  83ea9e5   07-16     4.26     21       0.009     기준
H-08  3fc36ed   07-17     1.00      0       0.009     ★회귀
```

**이 표가 있으면 회귀 국소화가 grep 이다.** 없어서 커밋 이등분에 열흘을 썼다.
`git bisect` 는 최후 수단이지 기본이 아니다 — 다만 **"왜"보다 "언제부터"를 먼저 묻는
습관 자체는 옳다.** 가설 공간은 안 닫히고 커밋 이력은 전순서라 로그 시간에 끝난다.

## G6 · 링크 선언 — 이것이 목표 사다리의 어디를 여는가

**왜 생겼나**: 목표선 위 실험이 소음에 밀린다는 실측에서. 사전등록 8건 중 목표 링크 위에
있던 것은 1건, 그리고 **그 1건이 유일한 양성**이었다. 회귀 부검은 즉각·확정·닫힘이고
**언제나 HEAD 이웃에 있다.** 목표는 느리고 멀다. **소음을 좇으면 정의상 로컬 미니마다.**

```
G6 = <링크 id> · <그 링크의 현재 상태> · <이 실험이 상태를 어떻게 바꾸나>
```

**못 대면 발사하지 않는다.** 링크를 못 대는 실험은 대부분 **소음 추적**이다 —
방금 난 회귀, 방금 본 이상한 수. 그것들은 EXP 트랙(§3)에서 공짜로 보되
**확증 슬롯을 먹지 못하게 한다.**

### 깨진 링크 위에서는 발사하지 않는다

사슬 A→F 중 C가 깨져 있으면 **C를 경유하는 팔은 널이 보장된다.**
발사 전에 사다리를 보고, 이 실험의 경로에 깨진 링크가 있으면 **그 링크를 먼저 고친다.**

### 예외 하나 — 우회 경로 탐색

**깨진 링크가 있는데 최종 링크(F)가 양성이면**, 가치는 그 링크를 우회해서 오고 있다.
이때는 **우회 경로를 특정하는 실험**이 최우선이다. 이 경우가 가장 값진 실험이고
동시에 **가장 자주 방치된다** — 신호가 조용하기 때문이다.

## G7 · 부호 검사 — 중간지표가 최종지표와 어떤 부호로 붙어 있나

**왜 생겼나**: G1~G6을 전부 통과한 개입이 **"부호가 반대인 지표" 위에 서 있었다.**
G3(해상도)은 *"지표가 움직이나"* 만 보고 *"올바른 방향으로 붙어 있나"* 는 안 본다.

**실측**: 세계모델 충실도를 올리는 개입을 설계하던 중 기존 로그로 회귀하니 **−0.90** 이었다 —
고착된 런이 정적 환경 덕에 가장 "정확한" 모델을 갖고 있었다.
**그 게이트가 행동 게이트로 배선됐다면 전진을 막았다.**

```
개입 전에 답할 것 (기존 로그만으로 2분):
  중간지표 <M> 와 최종지표 <F> 의 회귀/상관 부호 = ?   ← 새 실행 불필요
```

**규칙**: 부호가 음수면 그 지표를 올리는 개입은 설계하지 않는다.
음의 결합 자체가 발견이면 — 그것을 주장으로 CLAIMS 에 적는 것이 먼저다.

## G8 · 팔 정체 — 매니페스트 전 키 diff

**이름을 믿지 마라 — 이름은 캐시된 결론이다.** 팔 이름·태그·커밋 메시지는
이전 세션이 만든 요약이지 현재 상태의 증거가 아니다.

```bash
diff <(jq -S . runs/A/manifest.json) <(jq -S . runs/B/manifest.json)
# 이 diff 가 "내가 조작한다고 믿는 것"과 정확히 일치해야 한다. 불일치면 정지.
```

**왜 생겼나 (실측)**: 팔 태그가 `-on-`/`-off-` 라서 "라이브러리 켬/끔"으로 읽었다.
실제 차이는 `load_bundle` 유무였고, **매니페스트에 `imported_lineage` 라는 이름으로
그대로 적혀 있었다.** 같은 파일을 하루에 세 번 열었는데 매번 `grep <내가 찾는 플래그>` 로만
들어가서 못 봤다. **9시간 66런이 통째로 무효가 됐다.**
⇒ 조회(grep)는 **키에 대한 증거만** 돌려준다. 틀은 정교해질 수는 있어도 **반박될 수는 없다.**
레코드 하나를 **통째로** 읽는 것이 유일한 반박 수단이다.

**재발(0807)**: G8을 안 쳐서 — "복원했다"고 커밋된 기계가 **호출자 0** 인 채
그 팔이 통제군과 **바이트 동일**이었다. 상세: `case-studies.md` §15
